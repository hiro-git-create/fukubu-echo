# 脾梗塞 (Splenic Infarction)

> [!NOTE] 概要
> 脾梗塞は脾動脈またはその分枝の閉塞により脾実質が壊死する病態。心房細動・感染性心内膜炎・血液疾患・膵尾部癌による圧迫など多彩な原因で生じる。左季肋部痛が典型的な症状。

---

## 1. 病態と原因

### 主な原因
| カテゴリ | 具体的疾患 |
|---------|----------|
| **塞栓性** | 心房細動（最多）・感染性心内膜炎・大動脈手術後 |
| **血栓性** | 真性多血症・本態性血小板増多症・骨髄線維症 |
| **圧迫性** | 膵尾部癌・膵炎・転移性リンパ節 |
| **血管炎** | SLE・結節性多発動脈炎 |
| **外傷性** | 脾被膜下血腫からの進展 |

---

## 2. 超音波所見（時期別変化）

> [!IMPORTANT] 時期によって所見が大きく異なる
> 梗塞直後は等エコーで見えにくく、時間経過とともに典型像が出現する。

| 時期 | 超音波所見 |
|------|----------|
| **急性期（発症〜数日）** | くさび形（楔状）低エコー域、辺縁不整 |
| **亜急性期（1〜2週）** | 境界明瞭なくさび形低〜無エコー域 |
| **慢性期（数ヶ月〜）** | 高エコー化・石灰化・萎縮・瘢痕化 |
| **液化壊死** | 無エコー化（嚢胞様）→ 偽嚢胞形成 |

### ✅ 典型的な超音波所見
- **くさび形（楔状）低エコー域**：脾門部を頂点として被膜側に底辺
- **辺縁が脾被膜に接する**（被膜側に向いた三角形）
- **カラードプラ：梗塞部位に血流シグナルなし**
- 病変は単発または多発

---

## 3. カラードプラの役割

> [!IMPORTANT] カラードプラは必須
> Bモードで等エコーの急性期でも、カラードプラで欠損域として描出できる場合がある。血流の有無で梗塞を確認する。

- 梗塞巣：**血流シグナル欠如**（avascular）
- 周囲実質：正常血流あり
- 脾動脈本幹・脾静脈：開存確認（血栓・圧迫の評価）

---

## 4. スキャン手順

1. **右側臥位 + 肋間走査**：脾全体をスキャン
2. **低エコー域の探索**：くさび形・辺縁不整病変を探す
3. **カラードプラ**：病変部位の血流欠損を確認
4. **病変の計測**：最大径・範囲
5. **原因検索**：脾動脈・腹腔動脈の走行確認、膵体尾部の評価
6. **脾周囲液貯留**：出血・腹水の有無

---

## 5. 鑑別診断

| 鑑別疾患 | 鑑別ポイント |
|---------|------------|
| 脾膿瘍 | 発熱・炎症反応、内部debris・ガス像 |
| 脾嚢胞 | 壁が滑らか、真の無エコー、後方増強 |
| リンパ腫浸潤 | 多発結節、明瞭な低エコー球形病変 |
| 脾転移 | 原発巣あり、複数の不整形病変 |

---

## 6. レポート記載例

```
脾臓：上極に径 4.2 cm のくさび形低エコー域を認める。
カラードプラにて同部位に血流シグナルを認めず。
脾被膜側に底辺を有する楔状の無血流域であり、脾梗塞として矛盾しない。
心房細動の既往あり、塞栓性機序が最も疑われる。
```

---

## 7. 臨床的重要性

> [!WARNING] 合併症に注意
> - **脾膿瘍二次感染**：梗塞巣への感染、特に免疫抑制状態で注意
> - **脾破裂**：大型梗塞・外傷後では被膜破裂リスク
> - **偽嚢胞形成**：液化壊死後に大型偽嚢胞を形成し、圧迫症状をきたすことがある
