# 表在超音波 スクリーニング・死角克服ハンドブック

> [!NOTE] 概要
> 表在超音波検査において、病変の見落としが発生しやすい「死角（Blind spots）」と、その死角を攻略するための走査テクニック・臨床工夫をまとめた実践マニュアルです。

---

## 1. 臓器別 4大死角と攻略アプローチ

### (1) 甲状腺の死角：胸骨後甲状腺腫 ＆ 上極・気管背側
- **死角1: 胸骨後甲状腺腫 (Substernal Goiter)**
  - **解剖原因**: 下極が胸骨・鎖骨の背側に落ち込み、骨陰影で隠れる。
  - **攻略テクニック**:
    - 肩下に枕を入れ、**頸部を極度伸展**させる。
    - プローブを胸骨上窩に当て、ビームを**尾側から頭側に向かってアングル（傾斜）**させて覗き込む。
    - 患者に**嚥下動作（つばを飲み込む）**を指示し、甲状腺が頭側に挙上する瞬間を動的に観察・アプローチ。

- **死角2: 食道背側・反回神経走行部（気管傍 Level VI）**
  - **攻略テクニック**: 気管と総頚動脈の間の隙間にプローブを斜めから当て、食道の層構造や反回神経近傍のリンパ節転移を見落とさない。

### (2) 乳腺の死角：C領域外側・腋窩尾部・乳頭直下 (E領域)
- **死角1: C領域外側 ＆ 腋窩尾部 (Spence's Tail)**
  - **解剖原因**: 乳腺組織が腋窩に向かって落ち込み、背臥位では薄く伸びて体側へ逃げる。
  - **攻略テクニック**:
    - **半側臥位 (45°傾斜位)** をとり、乳腺組織を中心に寄せる。
    - 腋窩動静脈に平行・直交するスキャンで腋窩尾部からLevel Iリンパ節まで連続走査。

- **死角2: 乳頭直下 (E領域)**
  - **解剖原因**: 乳頭突起による強い音響陰影（Shadowing）。
  - **攻略テクニック**:
    - 乳頭を直接圧迫せず、たっぷりゼリーを盛る。
    - 乳頭側方から**斜めアングルスキャン（Angle Scan）**で乳頭直下の乳管を覗き込む。

### (3) 唾液腺・頭頸部の死角（吉川まどか先生『頭頸部診療とことんエコー活用術』より）
- **死角1: 耳下腺深葉 (Deep Lobe)**
  - **解剖原因**: 下顎枝・下顎角の骨陰影により深部領域が遮断される。
  - **吉川式アプローチ【開口走査 Open-mouth technique】**:
    - 頭部対側回旋 ＋ **「大開口指示（大きく口を開ける）」**。
    - 下顎骨頭が前方に滑り出ることで、下顎後角と胸鎖乳突筋の間のアプローチ窓が開大。斜め後方からビームを入れて深葉腫瘍（多形腺腫・悪性腫瘍）を描出。

- **死角2: 正中頸嚢胞（甲状舌管嚢胞）と舌骨背側**
  - **解剖原因**: 舌骨（骨影）の直下〜背側に病変が潜む。
  - **吉川式アプローチ【舌突き出し手技 Tongue protrusion】**:
    - 正中エコー走査中に患者に**「舌を外に突き出してもらう」**。
    - 甲状舌管遺残組織が舌根へ牽引される動的変化を捕捉。

- **死角3: 顎下腺Wharton管口腔底移行部（唾石症）**
  - **吉川式アプローチ【Cの字連続追跡走査】**:
    - 顎下腺主部から顎舌骨筋後縁を回り込み、オトガイ下から口腔底（舌下小頭直下）に至る**「Cの字走行」**を全周連続スライド走査。管内小唾石や導管拡張の見落としを完全回避。

## 2. チェックリスト：見落としゼロのためのスクリーニング順序

```
【甲状腺・頸部】
1. 峡部横断 ➔ 2. 右葉横断（上〜下極） ➔ 3. 右葉縦断 ➔ 4. 左葉横断 ➔ 5. 左葉縦断 
   ➔ 6. 嚥下指示（下極確認） ➔ 7. 左右Level II〜VIリンパ節走査

【乳腺】
1. 格子状全周走査 ➔ 2. 放射状スキャン（乳頭中心360°） ➔ 3. E領域斜めスキャン 
   ➔ 4. 腋窩尾部・腋窩Level I〜IIIリンパ節走査 ➔ 5. 鎖骨上リンパ節確認
```
