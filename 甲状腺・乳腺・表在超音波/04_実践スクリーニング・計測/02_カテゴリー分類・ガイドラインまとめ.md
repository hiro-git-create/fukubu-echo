# 超音波カテゴリー分類・ガイドライン集約バイブル

> [!NOTE] 概要
> 乳腺（JABTS / BI-RADS-US）および甲状腺（日本超音波医学会 / ACR TI-RADS）の超音波カテゴリー分類および診断ガイドラインの要点を臨床用に集約したリファレンスです。

---

## 1. 乳腺超音波カテゴリー分類 (JABTS 改訂第4版増補基準)

| カテゴリー | 定義・評価 | 臨床的対応・悪性確率 | 代表的病変所見（腫瘤 / 非腫瘤様病変） |
| :--- | :--- | :--- | :--- |
| **Category 1** | **異常所見なし (Negative)** | 精密検査不要 (悪性確率 0%) | 正常乳腺組織。 |
| **Category 2** | **良性所見 (Benign)** | 精密検査不要 (悪性確率 0%) | 単純嚢胞、定型的な線維腺腫 (FA)、乳腺内リンパ節、皮膚アテローム、ハムルトーマ。 |
| **Category 3** | **良性、しかし悪性を否定できない** | 精密検査 (精査) または**短期フォローアップ (6ヶ月後)** (悪性確率 >0% 〜 ≦2%) | ・**腫瘤**: 境界平滑な小低エコー結節、濃縮嚢胞、境界微細分葉状の横長結節。<br>・**非腫瘤様病変 (NML)**: 両側性・広範囲な乳管拡張、良性疑い小葉パターン。 |
| **Category 4** | **悪性疑い (Suspicious)** | **精密検査・精査要 (マンモグラフィ/細胞診 FNA/組織生検 CNB/VAB)** (悪性確率 2% 〜 95%) | 下記 4a / 4b / 4c に細分化。 |
| **- Category 4a** | **低度の悪性疑い** | 精査・生検考慮 (悪性確率 >2% 〜 ≦10%) | 主に良性所見を示すが、一部不整な境界や新しい出現所見を伴う病変。 |
| **- Category 4b** | **中度の悪性疑い** | 生検推奨 (悪性確率 >10% 〜 ≦50%) | 中等度の不整境界、D/W ≧ 0.7、不均一低エコー腫瘤、NMLの局所低エコー域。 |
| **- Category 4c** | **高度の悪性疑い** | **生検強く推奨** (悪性確率 >50% 〜 <95%) | 明らかなSpiculation、境界部高エコーハロー、NMLに伴う微小石灰化群。 |
| **Category 5** | **悪性確実 (Highly Suggestive of Malignancy)** | **精査・組織生検必須** (悪性確率 ≧ 95%) | 著しい不整形・Spiculation・腫瘤内微小石灰化・後方減衰・前/後境界線断裂・Cooper靭帯ひきつれ。 |

### ★ JABTS 判定フローのポイント（改訂第4版増補）
1. **腫瘤 (Mass) のカテゴリー判定アルゴリズム**:
   - 形状（丸/楕円/不整）、境界（平滑/不整）、後方エコー（増強/不変/減衰）、D/W比（<0.7 / ≧0.7）を統合。
   - 不整形 ＋ 境界不整（Spiculation / 角状） ＋ 境界部高エコーハローの重複で**Category 5**判定。
2. **非腫瘤様病変 (Non-mass lesion: NML) の判定アルゴリズム**:
   - 分布（片側性・局所的 vs 両側性・びまん性）、内部エコー、微小石灰化の有無、血流信号を評価。
   - **片側性・局所的な低エコー域**や**微小石灰化群**を認める場合は **Category 4 以上**で生検対象。

## 2. 甲状腺超音波診断ガイドライン・TIRADS (ACR TI-RADS ポイント制)

ACR TI-RADSは5つの画像要素（組成、エコー輝度、形状、境界、高エコー点）のポイント合計でリスク評価を行います。

| 評価項目 | 0ポイント | 1ポイント | 2ポイント | 3ポイント |
| :--- | :--- | :--- | :--- | :--- |
| **1. 組成 (Composition)** | 嚢胞 / 海綿状 | 嚢胞・固形混在 | 固形 (Solid) | - |
| **2. エコー輝度 (Echogenicity)** | 無エコー | 高エコー / 等エコー | 低エコー | **著明低エコー** |
| **3. 形状 (Shape)** | 横長 | - | - | **縦長 (Tall-than-wide)** |
| **4. 境界 (Margin)** | 平滑 | 境界不明瞭 | 微細鋸歯状 / 不整 | 被膜外浸潤 |
| **5. 高エコー点 (Echo foci)** | なし / コメットテール | 粗大石灰化 | 辺縁石灰化 | **微小石灰化 (<1mm)** |

### TRカテゴリー判定と対応基準
- **TR1 (0点)**: 悪性なし ➔ 生検不要
- **TR2 (2点)**: 非疑わしい ➔ 生検不要
- **TR3 (3点)**: 軽度疑い ➔ **≧ 2.5 cm** で生検
- **TR4 (4〜6点)**: 中等度疑い ➔ **≧ 1.5 cm** で生検
- **TR5 (7点以上)**: **高度悪性疑い** ➔ **≧ 1.0 cm** で生検（針生検 FNA）
