# 乳腺 良性腫瘍・嚢胞 超音波診断バイブル

> [!NOTE] 概要
> 乳腺の良性病変には、線維腺腫 (Fibroadenoma)、単純嚢胞 (Simple Cyst)、乳管内乳頭腫 (Intraductal Papilloma)、葉状腫瘍 (Phyllodes Tumor)、ハムルトーマ (Hamartoma) などが含まれます。
> JABTS『乳房超音波診断ガイドライン改訂第4版増補』に基づき、**カテゴリー2（良性確定）** と **カテゴリー3（良性、しかし要経過観察/精査）** を的確に鑑別・分類することが重要です。

---

## 1. 代表的良性病変の超音波像

### (1) 線維腺腫 (Fibroadenoma: FA)
- **疫学**: 20〜30代女性に最も頻度の高い良性上皮・間質混合腫瘍。
- **超音波所見**:
  - **形状**: **横長の楕円形 (Wider-than-tall / 縦横比 < 0.7)**。
  - **境界**: **平滑・整 (Smooth / Well-defined)**。連続した薄い被膜線像。
  - **内部エコー**: **均一な等エコー〜やや低エコー**。
  - **後方エコー**: **不変〜軽度増強**。両側縁に**エッジシャドウ (Lateral shadowing)**を伴う。

### (2) 乳腺嚢胞 (Breast Cyst)
- **超音波所見**:
  - **単純嚢胞 (Simple Cyst)**: 無エコー (Anechoic)、境界平滑、**著明な後方エコー増強**。
  - **濃縮嚢胞 (Complicated / Concentrated Cyst)**: 内部デブリス・蛋白成分により微細エコーが浮遊するが、圧迫で変形し、後方増強を維持。

### (3) 乳管内乳頭腫 (Intraductal Papilloma)
- **症状**: **単孔性・血性（または漿液性）乳頭分泌**。30〜50代。
- **超音波所見**:
  - **拡張した乳管内に存在する境界明瞭な隆起性低エコー結節**（乳管内結節像）。
  - カラードプラで結節茎部に血流信号（Feeding vessel）を認める。

### (4) 葉状腫瘍 (Phyllodes Tumor: PT)
- **特長**: 上皮成分と間質成分からなる。線維腺腫に酷似するが**急速に増大**（径3cm超）。
- **超音波所見**:
  - 大型、境界明瞭、**大分葉状 (Macrolobulated)**。
  - **内部に裂隙状（スリット状）無エコー領域**（嚢胞変性・出血）を伴う。
  - 悪性葉状腫瘍との鑑別のために全摘生検が必要。

## 2. 線維腺腫 (FA) vs 充実腺管癌 (悪性) 鑑別マトリックス

| 評価項目 | 線維腺腫 (FA / 良性) | 充実腺管癌 (Malignant) |
| :--- | :--- | :--- |
| **縦横比 (Depth/Width)** | **< 0.7 (横長)** | **> 0.7〜1.0 (縦長傾向)** |
| **境界** | 滑らか、連続性あり | 微細鋸歯状、一箇所でも境界不整 |
| **側方影 (Lateral Shadow)** | 明確なエッジシャドウあり | 欠損または不規則 |
| **内部の均一性** | 均一 | 不均一、微小石灰化混在 |
| **エラストグラフィ** | 柔らかい (Tsukuba Score 1〜2) | 硬い (Tsukuba Score 4〜5) |
