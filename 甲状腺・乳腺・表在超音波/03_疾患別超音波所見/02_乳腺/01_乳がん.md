# 乳がん (Breast Cancer) 超音波診断バイブル

> [!NOTE] 概要
> 乳がんは女性悪性腫瘍の第1位であり、超音波検査は日本乳腺甲状腺超音波医学会（JABTS）およびACR BI-RADSカテゴリー分類に基づき、腫瘍の境界・形状・内部エコー・後方エコー・周囲組織変化を統合評価します。

---

## 1. 乳がんの超音波悪性判定基準（JABTS 改訂第4版増補基準）

病変は**「腫瘤 (Mass)」**と**「非腫瘤様病変 (Non-mass lesion: NML)」**の2つに大別して系統的評価を行います。

### (1) 腫瘤 (Mass) の悪性徴候（JABTS 判定項目）
1. **形状 (Shape)**: **不整形 (Irregular)**（円形・楕円形でない）。
2. **境界 (Margin / Border)**: **不整 (Irregular)**
   - **Spiculation (棘状突出 / 微細鋸歯状)**: 癌性線維反応による周囲組織への浸潤。
   - **Microlobulation (微細分葉状)**: 1〜2mm単位の細かい刻み込み。
   - **Angular margin (角状)**: 病変辺縁が尖った角度を形成。
3. **境界部高エコーハロー (Echogenic Halo)**: 浸潤癌周囲のデスモプラジア（がん性線維増殖）を反映する高エコー帯。
4. **内部エコー (Internal Echo)**: **低エコー、不均一**。**点状微小石灰化 (Microcalcifications)**の描出。
5. **後方エコー (Posterior Echoes)**: **減衰 (Attenuation / Shadowing)**（硬癌に典型）、または**不変・増強**（充実腺管癌・粘液癌）。
6. **周囲構造変化 (Surrounding Tissue Alterations)**:
   - **前境界線の断裂・凸隆 (Anterior border line disruption / Bulging)**
   - **Cooper靭帯のひきつれ (Dimpling / Denting)**
   - **後境界線の断裂**（大胸筋浸潤）

### (2) 非腫瘤様病変 (Non-mass lesion: NML) の悪性評価パターン
腫瘤像を形成せず、主に**非浸潤性乳管癌 (DCIS)** や広範囲浸潤癌、小葉癌などで観察される重要病変。

| NMLの病術・パターン | 代表的エコー所見 | 主な対象疾患 |
| :--- | :--- | :--- |
| **低エコー域 (Hypoechoic area)** | 特定の領域に広がる境界不明瞭な低エコー構造。<br>・**乳管パターン**: 乳管に沿った枝分かれ状低エコー。<br>・**小葉・斑状パターン**: 局所的な斑状低エコーの集積。<br>・**広範囲・地図状パターン**: 区域性の不均一低エコー。 | **DCIS**、浸潤性小葉癌 (ILC)、乳管内進展、乳腺症 |
| **微小石灰化群** | 腫瘤を伴わない1mm以下の微小点状高エコーの集密。 | **DCIS (粉瘤型/コメド型)** |
| **乳管異常** | **乳管拡張 ＋ 管内不整低エコー病変**（単孔性分泌を伴いやすい）。 | DCIS、乳管内乳頭腫 |
| **建築構造の乱れ** | 明確な腫瘤を形成せず、乳腺構造・Cooper靭帯が集約・歪曲。 | DCIS、硬癌初期、術後瘢痕 |

## 2. 病理組織型別 超音波所見一覧

### (1) 浸潤性乳管癌 (Invasive Ductal Carcinoma: IDC) - 3大亜型

| 組織型 | 頻度 | 超音波画像の特徴 | 後方エコー & 血流 |
| :--- | :--- | :--- | :--- |
| **硬癌**<br>(Scirrhous CA) | 約40% | 強い癌性線維増殖を伴う。**著しい不整形・Spiculation・強い後方音響陰影（減衰）**。腫瘍径よりエコー上の影が大きく見える。前境界線の凸隆・断裂。 | 著しい後方エコー減衰。内部血流は流速高く不規則。 |
| **乳頭腺管癌**<br>(Papillotubular CA) | 約30% | 境界比較的明瞭、微細分葉状。**内部不均一低エコー、微小石灰化の集密**。| 後方エコーは不変〜軽度増強。 |
| **充実腺管癌**<br>(Solid-tubular CA) | 約20% | 膨大性成長。楕円形〜円形、境界明瞭、大分葉状。一見良性（線維腺腫）に類似するが、**内部エコーが不均一で著しい低エコー**。 | 後方エコー増強を伴いやすい。豊富な内部血流。 |

### (2) 非浸潤性乳管癌 (Ductal Carcinoma in Situ: DCIS)
- 上記の**非腫瘤様病変 (Non-mass lesion: NML)** パターン（乳管に沿った低エコー、微小石灰化群、管内病変）が診断の主体。
- 高周波リニア・SMI等の微細血流評価が有用。

### (3) 特殊型乳癌 (Special Types)
- **粘液癌 (Mucinous CA)**: 境界明瞭、円形〜楕円形、内部ゼラチン状粘液により**均一〜微細高エコー＋著しい後方エコー増強**（嚢胞と誤認しやすいがカラードプラで血流あり）。
- **浸潤性小葉癌 (Invasive Lobular Carcinoma: ILC)**: 腫瘤を形成しにくく、**非腫瘤様病変（広範囲低エコーや構造の乱れ）** として描出。偽陰性になりやすい。
- **葉状腫瘍 (Phyllodes Tumor: 悪性)**: 急速増大、分葉状、多房性嚢胞変性。

---

## 3. カラードプラ ＆ エラストグラフィ評価

- **ドプラ所見**: 腫瘍内部に侵入する**不規則・屈曲した穿通血管 (Penetrating vessels)**、高いRI (Resistance Index > 0.70)。
- **Strain / SWE エラストグラフィ**:
  - 悪性腫瘍は**極めて硬い (Hard: 高ヤング率 > 80-100 kPa)**。
  - **Tsukuba Score 4〜5**: 腫瘍内部だけでなく、**周囲の線維性反応領域まで硬い領域が広がっている（歪まない）**のが癌の特徴。
