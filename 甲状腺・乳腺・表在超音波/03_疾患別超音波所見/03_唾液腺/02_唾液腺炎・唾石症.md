# 唾液腺炎・唾石症 (Salivary Inflammatory & Calculus Diseases) 超音波診断バイブル

> [!NOTE] 概要
> 唾液腺の非腫瘍性病変において、唾石症（特に顎下腺）および各種唾液腺炎（急性・慢性・シェーグレン症候群）の迅速かつ正確な超音波診断は、排石処置や保存的治療の方針決定に直結します。

---

## 1. 唾石症 (Sialolithiasis)

- **好発部位**: **約80〜90%が顎下腺（Wharton管）**に発生（粘調度の高い唾液と重力方向の走行による）。耳下腺（Stensen管）は10〜20%。
- **臨床症状**: 食事のたびに唾液腺が痛む・腫れる（**唾液仙痛: Salivary Colic**）。
- **超音波所見**:
  - **唾石の直描**: **強烈な弧状高エコー (Curvilinear Hyperechoic Spot) ＋ 明瞭な後方音響陰影 (Acoustic Shadowing)**。
  - **導管拡張**: 結石より中枢側の唾液腺管（Wharton管）が**無エコー管状構造として著明に拡張**（管径 3mm以上）。
  - **腺体変化**: 閉塞に伴ううっ滞性唾液腺炎により、腺体全体が腫大し不均一低エコー化。

```
[ 顎下腺腺体 (腫大・不均一低エコー) ]
      ↓
[ 拡張したWharton管 (無エコー管状構造) ]
      ↓
[ ★ 唾石 (強烈な高エコー spot) ] ═══> 【明瞭な後方音響陰影 (Shadowing)】
```

## 2. 唾液腺炎 (Sialadenitis)

### (1) 急性化膿性唾液腺炎 (Acute Suppurative Sialadenitis)
- **超音波所見**:
  - 腺体の著明な腫大、実質の全体的低エコー化・不均一化。
  - カラードプラで**腺体全体の著しい血流増加 (Hyperemia)**。
  - 膿瘍形成（Abscess）を伴う場合は、内部デブリスを含む無/低エコー領域が出現。

### (2) シェーグレン症候群 (Sjögren's Syndrome)
- **病態**: 涙腺・唾液腺を標的とする慢性自己免疫性外分泌腺炎。
- **超音波所見**:
  - 両側耳下腺・顎下腺に**網目状・斑状の小低エコー領域の多発 (Reticular / Hypoechoic spotty pattern / Leopard-skin / Snowstorm sign)**。
  - 腺体境界の不整、腺体萎縮・不均一化。

### (3) IgG4関連唾液腺炎 (IgG4-related Dacryoadenitis & Sialadenitis / ミクリッツ病)
- **超音波所見**:
  - 両側耳下腺・顎下腺が**無痛性に著明に腫大**。
  - 実質内部に複数の境界比較的明確な結節様低エコー領域（Multiple hypoechoic nodules）が散在。カラードプラで豊かな血流。
