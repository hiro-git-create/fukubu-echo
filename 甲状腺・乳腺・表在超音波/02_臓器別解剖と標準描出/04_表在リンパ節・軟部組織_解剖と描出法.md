# 表在リンパ節・軟部組織 解剖と標準描出プロトコル

> [!NOTE] 概要
> 頸部をはじめとする表在リンパ節および皮下軟部組織の超音波評価では、リンパ節のレベル分類（頸部Level I〜VI）の理解と、皮膚〜皮下脂肪〜筋膜〜筋肉の層構造の解剖的特定が重要です。

## 2. 正常リンパ節の超音波像の特徴

- **形状**: 扁平な楕円形（Longitudinal/Transverse Ratio: **L/S比 ≧ 2.0**）。
- **リンパ節門 (Lymph Node Hilus)**: 門部は**線条の高エコー**として中心部に明確に描出される（脂肪・血管網）。
- **皮質 (Cortex)**: 均一で薄い低エコー（皮質厚 2mm以下）。
- **血流パターン**: カラードプラ/パワードプラで、門部から規則正しく放散する**門部血流（Hilar vascularity）**のみを検出。

---

## 3. 皮膚・皮下軟部組織の解剖的層構造

```
[ 表皮・真皮 (Epidermis & Dermis: 1〜2mmの薄い高エコー層) ]
  ↓
[ 皮下脂肪層 (Subcutaneous Tissue: 小葉構造を示す低エコー＋線維性高エコー隔壁) ]
  ↓
[ 浅筋膜 (Superficial Fascia) ]
  ↓
[ 筋層 (Muscle Layer: 筋線維束の羽状/線条高エコーパターン) ]
  ↓
[ 骨膜・骨表面 (Periosteum / Bone Surface: 強烈な高エコー + 完璧な音響陰影) ]
```

> [!TIP] 臨床観察のポイント
> 軟部腫瘤を発見した場合、腫瘤がどの層（表皮・皮下・筋膜・筋内・筋間）から発生しているかを縦断・横断像で慎重に同定することが、アテローム・脂肪腫・神経鞘腫・筋肉内血腫などの確定診断につながります。
