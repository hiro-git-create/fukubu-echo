# AHA 17セグメントモデルと冠動脈支配領域

局所壁運動異常 (Regional Wall Motion Abnormality: RWMA) を正確に記録し、責任冠動脈病変を特定するために、左室を17の領域（セグメント）に分割する **AHA (米国心臓協会) 17セグメントモデル** が標準として使用されます。

---

## 1. 17セグメントの立体的解剖とレベル分け

左室は、長軸方向に **基部 (Basal: 1〜6)**、**中間部 (Mid: 7〜12)**、**心尖部 (Apical: 13〜16)** の3レベル（計16区分）と、最先端の **心尖部キャップ (Apical Cap: 17)** に分けられます。

```
【Bull's-eye (ブルズアイ) マップにおける17セグメント配置】

                   1. 前壁基部 (Ant)
             12. 前側壁   │   7. 前壁中隔
               (AntLat)   │    (AntSept)
             ─────────────┼─────────────
             11. 下側壁   │   8. 下壁中隔
               (InfLat)   │    (InfSept)
                   4. 下壁基部 (Inf)
```

## 2. 冠動脈3枝の支配領域対応表

冠動脈の走向には解剖学的バリエーションがありますが、標準的な支配領域は以下の通りです。

```mermaid
pie title 冠動脈支配領域の標準割合
    "LAD("左前下行枝: 前壁・中隔・心尖部")" : 45
    "RCA("右冠動脈: 下壁・下壁中隔・右室")" : 35
    "LCx("左回旋枝: 側壁・後壁")" : 20
```

### 1) LAD (左前下行枝: Left Anterior Descending)
- **支配領域**: 前壁（Seg 1, 7, 13）、前壁中隔（Seg 2, 8）、心尖部全般（Seg 14, 15, 16, 17）。
- **特徴**: 左室収縮能への影響が最も大きく、広範前壁梗塞では高度なLVEF低下と心不全を来します。

### 2) RCA (右冠動脈: Right Coronary Artery)
- **支配領域**: 下壁（Seg 4, 10）、下壁中隔（Seg 3, 9）、右室自由壁。
- **特徴**: 下壁梗塞においては、**右室梗塞 (RV Infarction)** や後内側乳頭筋断裂の併発に注意します。

### 3) LCx (左回旋枝: Left Circumflex)
- **支配領域**: 前側壁（Seg 6, 12）、下側壁（Seg 5, 11）。
- **特徴**: 側壁・後壁領域は心エコーの死角になりやすいため、側壁専用の心尖部描出を意識します。
