# 僧帽弁輪石灰化（MAC）と心臓石灰化無定形腫瘍（CAT）

本ページでは、高齢者や人工透析（末期腎不全：ESRD）患者等で遭遇する**僧帽弁輪石灰化（MAC）**、MACを背景として発症する稀な非腫瘍性結節**心臓石灰化無定形腫瘍（CAT）**、および両者が引き起こす**多発脳梗塞・全身性塞栓症リスクと手術適応・心エコー鑑別診断**について詳細に解説します。

---

## 1. 疾患の概要と概念

### ■ 僧帽弁輪石灰化（MAC: Mitral Annular Calcification）
- **定義**: 僧帽弁の周囲（特に後尖基部弁輪）にカルシウムおよび脂質が慢性的に沈着・石灰化した退行性病変。
- **好発背景**: 高齢者、高血圧、動脈硬化、**末期腎不全（ESRD / 人工透析患者）**、カルシウム・リン代謝異常。
- **臨床的意義**: 単なる加齢変化だけでなく、重症化すると**僧帽弁狭窄症（MS）/ 逆流症（MR）**、心房細動（AF）、伝導障害、そして**塞栓症（脳梗塞）のリスク因子**となる。

### ■ 心臓石灰化無定形腫瘍（CAT: Cardiac Calcified Amorphous Tumor）
- **定義**: 結節性の無定形石灰化、慢性炎症組織、フィブリン、血栓成分から構成される**非常に稀な心腔内非腫瘍性（非新生物性）結節・腫瘤**。
- **MACとの関連**: 多くのCATは**MAC（僧帽弁輪石灰化）を発生母体・発生基盤**として生じる（MAC-related CAT）。
- **最大の問題点**: 腫瘤表面の脆弱な微細石灰化破片や血栓が飛散し、**多発脳梗塞（Ischemic Stroke）や一過性脳虚血発作（TIA）、網膜動脈閉塞などの高度な全身性塞栓症**を引き起こす。

### ■ 関連病態：僧帽弁輪干酪様石灰化（CCMA: Caseous Calcification of the Mitral Annulus）
- **特徴**: MACの特殊型。石灰化の被幕（シェル）の内部に、歯磨き粉状（toothpaste-like）の粘稠な干酪様（caseous）液状物質が充満した病変。
- **CATとの関係**: CCMAの被膜が破綻・微細損壊することで、内部物質や血栓が反応性に結節化しCATへ移行・併発することが報告されている。

---

## 2. 病態メカニズムと脳梗塞・塞栓症リスク

```
【発生・塞栓メカニズム】
高齢 / 腎不全 (ESRD) / カルシウム代謝異常
       │
       ▼
僧帽弁輪石灰化 (MAC) の進行
       │
       ├─ (微細損壊・慢性炎症・血栓沈着) ──► 心臓石灰化無定形腫瘍 (CAT) 形成
       │                                       │
       │                                       ▼
       └─────────────────────────────► 微細石灰化片・脆弱血栓の飛散
                                               │
                                               ▼
                                      多発性脳梗塞 (Stroke) / TIA
```

1. **MACからCATへの発生**:
   - 機械的ストレス（弁動態）や脂質・カルシウム微細破綻により、MAC表層にフィブリンや血栓が付着。
   - そこへ慢性炎症反応と更なる石灰化沈着が重なることで、有茎性または無茎性の結節性腫瘤（CAT）へと成長する。
2. **脳梗塞・全身性塞栓症リスク**:
   - CATは真の腫瘍ではなく、脆弱な石灰化物質と血栓の混在物であるため、**微小破片が容易に剥離・飛散**する。
   - 特に**可動性（Mobile）を有する有茎性CAT**は、無症状であっても塞栓症発症率が極めて高い。

---

## 3. 心エコー（TTE / TEE）診断と観察ポイント

心エコー検査（経胸壁TTE / 経食道TEE）は、MACおよびCATの検出、可動性評価、塞栓リスク評価において最も重要な第一選択画像診断です。

### 1. 観察手順とチェックリスト
- [ ] **発生部位**: 僧帽弁輪部（特に後尖基部/P2〜P3付着部）の石灰化領域に一致しているか。
- [ ] **エコー輝度と内部構造**: 音響陰影（Acoustic shadowing）を伴う高輝度（強回音）エコー。内部は不均一。
- [ ] **形態と可動性 (Mobility)**: 茎（pedicle）の有無、心周期（収縮期/拡張期）に応じた左室・左房へのゆらめき（可動性）の有無。
- [ ] **弁機能への影響**: 僧帽弁口の狭窄（Mean PG上昇）や、弁葉可動制限による逆流（MR）の併発。

### 2. 経食道心エコー（TEE）の役割
- TTEで観察困難な微小な可動性結節（CAT）や、茎の付着部（MAC本体との境界）の精査には**経食道心エコー（TEE）が必須**。
- 塞栓症を既往した症例では、TEEで可動性（Mobility）の有無をミリ単位で確認する。

---

## 4. 心腔内異常構造物の鑑別診断マトリックス

MAC/CATは、心内血栓、疣贅（Vegetation）、粘液腫などとの鑑別が臨床上極めて重要です。

| 疾患名 | 発生好発部位 | 心エコー所見（輝度・性状） | 可動性 | 臨床的特徴・鑑別点 |
| :--- | :--- | :--- | :---: | :--- |
| **MAC** | 僧帽弁輪（主に後尖基部） | 音響陰影を伴う強回音（高輝度）な弓状・三日月状壁 | なし | 高齢・透析患者。弁輪に固定。 |
| **CAT** | **MAC・僧帽弁輪部周辺** | **高輝度・内部不均一な石灰化結節/腫瘤** | **あり〜なし** | **MACを母体とし、塞栓症（脳梗塞）リスクが極めて高**。 |
| **CCMA** | 僧帽弁後尖基部 | **周囲が高輝度で内部が低回音（無回音）の滑らかな塊** | なし | 内部が歯磨き粉状。経時的に自然消退・変化することがある。 |
| **左房粘液腫 (Myxoma)** | 卵円孔縁（心房中隔） | 内部不均一、分葉状、嚢胞様領域を含む | **顕著にあり** | 最も頻度の高い心内真性腫瘍。心房中隔に有茎性付着。 |
| **疣贅 (Vegetation)** | 弁葉閉鎖線（血流の低圧側） | 茎を持たない不規則な揺らめく微小構造物 | **あり** | **感染性心内膜炎（IE）**。発熱、血培陽性、弁破綻を伴う。 |
| **心内血栓 (Thrombus)** | 左室心尖部、左心耳 | 比較的低〜中等度回音、無反射領域と連続 | あり〜なし | 壁運動低下領域（AMI後、DCM）や心房細動（AF）に合併。 |

## 5. 治療方針と外科的手術適応

MACに併発したCATや可動性石灰化病変に対する治療方針は、**塞栓リスクと手術リスク（高齢・透析等の全身状態）のバランス**を考慮して決定されます。

### ■ 外科的手術適応（切除術＋弁形成/置換）
以下のいずれかを満たす場合、**無症状であっても予防的外科切除が強く考慮・推奨**されます。

1. **有症状例（塞栓症の既往）**:
   - 多発脳梗塞、TIA、網膜動脈閉塞などの塞栓症を既に発症している場合（絶対的手術適応）。
2. **高度な可動性（Mobile mass）を認める場合**:
   - 経食道心エコー（TEE）で腫瘤に明確な可動性・ゆらめきが認められ、飛散リスクが高い場合。
3. **腫瘤の経時的拡大または高度な弁機能障害（MR/MS）併発例**:
   - 経過観察中に腫瘤が拡大している場合や、血流障害を引き起こしている場合。

> [!WARNING]
> **手術時の注意点**
> MAC/CAT切除術では、石灰化が弁輪深部や心筋層まで及んでいることが多く、石灰化破片の術中飛散防止や、弁輪再構築（Mitral Annular Reconstruction）に高度な外科手技を要します。

### ■ 保存的治療（抗凝固・抗血小板療法）
- **対象**: 手術超ハイリスク患者（超高齢、重症透析・全身状態不良例）や、小型で可動性のない固定性CAT/MAC。
- **方針**: ワルファリンやDOACによる抗凝固療法、または抗血小板療法を行いつつ、**定期的な心エコー（TTE/TEE）による腫瘤サイズ・可動性の厳重な監視**を実施する。

## 6. 臨床で役立つ3秒まとめ

| チェック項目 | 観察ポイントと臨床アクション |
| :--- | :--- |
| **1. 僧帽弁輪の石灰化（MAC）を発見したら** | 石灰化の表層や周囲に、**ゆらめく結節（CAT疑い）がないか**を慎重にスクリーニングする。 |
| **2. 可動性のある高輝度結節を見つけたら** | 脳梗塞・塞栓症ハイリスク。**直ちに経食道心エコー（TEE）を依頼し、脳神経内科/心臓血管外科へコンサルト**。 |
| **3. 脳梗塞患者で心原性塞栓源を探すとき** | 粘液腫や血栓だけでなく、**MAC / CAT などの石灰化無定形腫瘍も重要発生源**として観察する。 |
