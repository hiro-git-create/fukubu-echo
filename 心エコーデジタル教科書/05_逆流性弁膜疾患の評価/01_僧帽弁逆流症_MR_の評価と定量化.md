# 僧帽弁逆流症 (MR) の評価と定量化

僧帽弁逆流症 (Mitral Regurgitation: MR) は、弁の構造的破綻（一次性）または左室・弁輪の拡大による接合不全（二次性）によって生じます。超音波エコーはメカニズムの特定と重症度定量化に不可欠です。

---

## 1. MR のメカニズム分類 (一次性 vs 二次性)

```mermaid
graph TD
    A[僧帽弁逆流症 MR] --> B[一次性 MR: Primary / Organic]
    A --> C[二次性 MR: Secondary / Functional]
    
    B --> B1[弁尖・腱索・乳頭筋自体の構造的破綻]
    B1 --> B2[弁脱垂 Prolapse, 腱索断裂 Flail, 感染性心内膜炎 IE]
    
    C --> C1[左室・左房の形態変化による弁接合不全]
    C1 --> C2[左室拡大・乳頭筋偏位 Tethering (DCM/虚血), 弁輪拡大]
```

---

## 2. 定性・半定量評価法

### 1) カラードプラ法 (Color Jet Area)
- **方法**: 左房内に広がるカラージェットの面積を評価。
- **注意点**: 偏心性ジェット（Coanda効果により壁に沿うジェット）では面積が実際より著しく小さく表示されるため、過小評価の危険があります。

### 2) Vena Contracta (VC: 縮小断面幅)
- **定義**: カラードプラにおいて、逆流口（弁の接合部）の直下で最も血流束が狭くなる首（ネック）の部分の幅。
- **断面**: PLAX や AP4 で拡大観察。
- **判定基準**:
  - **軽度 (Mild)**: **$< 0.3 \text{ cm}$**
  - 中等度 (Moderate): $0.3 \sim 0.69 \text{ cm}$
  - **重症 (Severe)**: **$\ge 0.7 \text{ cm}$** ($7\text{mm}$ 以上)

### 3) 肺静脈血流波形 (Pulmonary Vein Flow)
- **方法**: AP4から右上の肺静脈にPWドプラ（サンプル2cm奥）を当てます。
- **判定**: 重症MRでは、収縮期に左房圧が急上昇するため、**収縮期逆行波 (Systolic Flow Reversal)** が出現します。

---

## 3. 定量評価法：PISA法 (Proximal Isovelocity Surface Area)

PISA法は、逆流口の手前（左室側）に形成される半球状の流速等速曲面を利用して、逆流口面積 (EROA) と 逆流量 (RegVol) を求める**最も厳密な定量法**です。

```
【PISA（半球状等速表面積）の概念図】
       左室側 (LV)
        ＼  r (半径)  ／  ← Aliasing Velocity (Va)
          ＼  半球  ／
      ────────逆流口 (EROA) ─────── 
          ／  ジェット  ＼
       左房側 (LA)
```

### 1) PISA法の計測手順
1. AP4断面で僧帽弁口を拡大表示し、カラードプラのベースラインを**下向き（逆流方向）にシフト**させ、半球状のエイリアシング境界（赤から青に切り替わる線）を綺麗に出します。
2. エイリアシング流速 ($V_a$) を **$30 \sim 40 \text{ cm/s}$** 程度に設定します。
3. 逆流口から等速半球の境界までの**半径 $r$ (cm)** を計測します。
4. CWドプラでMRの最高血流速度 ($V_{max}$) と 速度時間積分 ($VTI_{MR}$) を計測します。

### 2) 計算式
$$\text{逆流流量 } Q = 2 \pi r^2 \times V_a$$
$$\text{有効逆流口面積 } \text{EROA (cm}^2) = \frac{2 \pi r^2 \times V_a}{V_{max}}$$
$$\text{逆流量 } \text{RegVol (mL)} = \text{EROA} \times VTI_{MR}$$

## 4. MR 重症度判定基準一覧 (ASE 2017 / JCS 2020)

| 指標 | 軽度 (Mild) | 中等度 (Moderate) | 重症 (Severe) ★一次性 | 重症 (Severe) ★二次性 |
| :--- | :--- | :--- | :--- | :--- |
| **Vena Contracta (cm)** | $< 0.3$ | $0.3 \sim 0.69$ | **$\ge 0.7$** | **$\ge 0.7$** |
| **EROA (cm²)** | $< 0.20$ | $0.20 \sim 0.39$ | **$\ge 0.40$** | **$\ge 0.20 \sim 0.30$** (※少容量で重症) |
| **RegVol (mL)** | $< 30$ | $30 \sim 59$ | **$\ge 60$** | **$\ge 30 \sim 45$** |
| **肺静脈血流** | 正常 (収縮期優位) | 収縮期波低下 | **収縮期逆行波 (Reversal)** | 収縮期逆行波 |
| **左室・左房の形態** | 正常 | やや拡大 | **左房・左室の著明拡大** | 原因基礎疾患による |

> [!CAUTION]
> **二次性MR (Functional MR) における重症度基準の注意**
> DCMや虚血による二次性MRでは、左室機能障害を伴うため、**EROA $\ge 0.20 \text{ cm}^2$、RegVol $\ge 30 \text{ mL}$ の比較的少ない逆流量であっても予後不良（重症と同等）**と判断されます。
