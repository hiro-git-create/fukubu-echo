# 脂肪肝 (Fatty Liver / Hepatic Steatosis) 診断プロトコル

> [!NOTE] 概要
> 脂肪肝は肝細胞内へのトリグリセリドの異常蓄積により生じます。超音波検査は脂肪肝の非侵襲的スクリーニングおよび重症度評価（軽度・中等度・高度）における第一選択の検査法です。

---

## 1. 診断の4大エコーサイン (Ultrasound 4 Signatures)

```text
 ┌────────────────────────────────────────────────────────┐
 │ 1. 輝度上昇: Bright liver sign                        │
 │ 2. コントラスト増強: 肝腎コントラスト (Liver-Kidney contrast)  │
 │ 3. 深部減衰: Deep attenuation (横隔膜描出不良)          │
 │ 4. 血管壁不鮮明化: Vascular blurring (門脈壁エコーの消退) │
 └────────────────────────────────────────────────────────┘
```

---

## 2. 脂肪肝の重症度分類 (Grade Classification)

| 重症度 (Grade) | 肝腎コントラスト | 深部減衰 (Deep Attenuation) | 肝内血管描出 (Vascular Blurring) | 横隔膜描出 |
| :--- | :--- | :--- | :--- | :--- |
| **正常 (Normal)** | 肝実質と腎皮質の輝度が同等 | なし（深部まで均一描出） | 門脈壁の高エコーが鮮明 | 鮮明に描出 |
| **軽度 (Mild)** | 軽度陽性（肝がわずかに明るい） | なし～極軽度 | 門脈壁は保たれる | 鮮明 |
| **中等度 (Moderate)** | 明らかな陽性（肝輝度の上昇） | 軽度（肝深部輝度が低下） | 門脈壁エコーがやや不鮮明 | やや描出不良 |
| **高度 (Severe)** | 著明な陽性（肝輝度が著しく高値） | 著明（肝深部が描出不能） | 肝内脈管がほとんど描出不能 | 描出不可（遮蔽） |

---

## 3. 局所性脂肪異常沈着・回避の鑑別 (Focal Fatty Change / Sparing)

脂肪肝には全般性ではなく局所に偏在する病変があり、**腫瘍との鑑別**が極めて重要です。

### 1) 局所性脂肪回避 (Focal Fatty Sparing)
- **好発部位**:
  - **胆嚢床近傍 (S5)**
  - **門脈分岐部前方 (S4)**
  - **肝被膜下・静脈索索近傍 (S1/S2)**
- **超音波所見**: 脂肪沈着背景の中に存在する**低エコー領域**。
- **鑑別ポイント**: **Mass effect (占拠性効果) がない**（周囲血管を走行変化・圧迫させない）。

### 2) 局所性脂肪沈着 (Focal Fatty Infiltration)
- **超音波所見**: 正常背景の中に存在する**高エコー領域**。
- **鑑別ポイント**: 境界が地理的状（Map-like）で、血管走行を乱さない。

## 4. 診断フローチャート

```mermaid
flowchart TD
    A[上腹部走査: 肝腎長軸像・右肋骨下像] --> B[肝腎コントラスト評価]
    B --> C{肝輝度 > 腎皮質輝度?}
    C -- No --> D[正常肝 (Normal)]
    C -- Yes --> E[深部減衰 & 門脈壁不鮮明化の評価]
    E --> F{深部減衰あり?}
    F -- No --> G[軽度脂肪肝 (Mild)]
    F -- Yes --> H{横隔膜描出可能?}
    H -- Yes --> I[中等度脂肪肝 (Moderate)]
    H -- No --> J[高度脂肪肝 (Severe)]
```
