# 急性虫垂炎 (Acute Appendicitis) 診断プロトコル

> [!NOTE] 概要
> 急性虫垂炎は右下腹部痛を来す代表的な外科的緊急疾患です。高周波リニアプローブを用いた段階的圧迫走査 (Graded Compression Technique) により高い精度で診断できます。

---

## 1. 診断の主要エコー所見 (Diagnostic Signatures)

```text
 ┌────────────────────────────────────────────────────────┐
 │ 1. 虫垂外径の拡大: > 6.0 mm (7.0 mm 以上で確定)         │
 │ 2. 圧迫非消退性 (Non-compressible Round Structure)      │
 │ 3. 虫垂壁厚肥厚: > 2.0 ～ 3.0 mm (層構造肥厚)            │
 │ 4. 糞石 (Appendicolith): 陰影を伴う高エコー結節         │
 │ 5. 周囲脂肪組織の輝度上昇 (High-echoic Fat Tissue / Target) │
 │ 6. 超音波 Sonographic McBurney 徴候 陽性               │
 └────────────────────────────────────────────────────────┘
```

```mermaid
flowchart TD
    A[右下腹部圧迫走査: 回盲部 Bauhin弁の同定] --> B[盲端で終わる管状構造の描出]
    B --> C{虫垂外径 > 6.0 mm?}
    C -- Yes --> D{プローブ圧迫で潰れるか?}
    D -- 潰れない (圧迫非消退) --> E[カラードプラで壁内血流増強?]
    E -- Yes --> F[急性虫垂炎 (Acute Appendicitis) 診断確定]
    C -- No --> G[正常虫垂 (Normal Appendix)]
```

---

## 2. カタル性・蜂窩織炎性・壊疽性の期別鑑別

| 期別分類 | 虫垂径 | 壁層構造 | 壁内血流 (Color Doppler) | 周囲所見 |
| :--- | :--- | :--- | :--- | :--- |
| **カタル性 (Catarrhal)** | 6～8 mm | 5層構造が鮮明 | 軽度増強 | 脂肪輝度変化なし |
| **蜂窩織炎性 (Phlegmonous)** | 8～12 mm | 粘膜下層の著明肥厚 | **著明増強 (Hyperemia)** | 周囲脂肪組織の高エコー化 |
| **壊疽性 (Gangrenous)** | > 10 mm | **層構造の断裂・消失** | **血流信号の消失 (無血流)** | 虫垂周囲液貯留、穿孔 |
