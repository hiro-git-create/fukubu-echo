# 膵がん (Pancreatic Carcinoma) 超詳細診断プロトコル

> [!NOTE] 概要
> 膵浸潤性管がんは予後が極めて不良な難治性がんです。直接腫瘍像の描出困難例においても、**主膵管拡張 (>2mm)** や **ダブルダクトサイン (Double Duct Sign)** などの間接所見から早期発見へ繋げるプロトコルを精緻に解説します。

---

## 1. 早期判定のための「間接所見 (Indirect Signs)」

超音波検査において、直接腫瘍が描出される前の段階で捉えるべき間接サインです。

```text
 ┌────────────────────────────────────────────────────────┐
 │ 1. 主膵管拡張 (MPD Dilatation): 膵体部径 > 2.0 mm (特に > 3.0 mm)│
 │ 2. 主膵管の突然の途絶 (Abrupt Cut-off Sign)            │
 │ 3. ダブルダクトサイン (Double Duct Sign): CBD ＋ MPD 同時拡張│
 │ 4. 膵外形の局所的変形・局所性膵萎縮                      │
 │ 5. 膵嚢胞の出現 (腫瘍末梢側の閉塞性嚢胞)               │
 └────────────────────────────────────────────────────────┘
```

### ダブルダクトサイン (Double Duct Sign) の機構
- **病態**: 膵頭部に発生した小腫瘍が、近接して平行走行する **総胆管 (CBD)** と **主膵管 (MPD)** の両方を同時に包囲・閉塞させる現象。
- **超音波像**: 膵頭部側で CBD ( > 7mm ) と MPD ( > 3mm ) が「2本の拡張した並走管状構造」として描出される。

---

## 2. 直接腫瘍像 (Direct Tumor Findings)

- **腫瘤性状**: **境界不鮮明な低エコー腫瘤 (Hypoechoic Mass)**。
- **内部エコー**: 不均一で、後方エコー減衰 (Posterior Echo Attenuation) を伴いやすい（高度の線維性基質 Stromal Fibrosis のため）。
- **周囲血管浸襲 (Vascular Encasement)**:
  - **上マゼンタ系動脈 (SMA)** / **腹腔動脈 (CA)**: 腫瘍による周囲包囲。
  - **門脈幹 (PV)** / **脾静脈 (SV)**: 管腔狭窄、管腔内突出、閉塞。
