# 転移性肝がん (Metastatic Liver Tumor) 診断プロトコル

> [!NOTE] 概要
> 消化管がん（大腸がん・胃がん）、膵がん、肺がん、乳がんなど他臓器の悪性腫瘍から門脈血流や肝動脈を介して肝に転移した病変です。超音波検査では多発性結節として発見されることが多いです。

---

## 1. 特徴的な超音波サイン (Ultrasound Signatures)

```text
 ┌────────────────────────────────────────────────────────┐
 │ 1. Target sign / Bull's eye sign (標的像・牛眼像)         │
 │ 2. 多発性結節 (Multiple Nodules)                        │
 │ 3. 腫瘍の集簇・融合 (Cluster / Confluence sign)         │
 │ 4. 肝外側縁の変形・突き出し (Umbilication / Extrusion)     │
 └────────────────────────────────────────────────────────┘
```

### Bull's eye sign / Target sign の構造解剖
- **中央高エコー (Central High Echo)**: 腫瘍中央部の壊死、凝固、石灰化。
- **周縁厚い低エコー帯 (Thick Hypoechoic Halo)**: 周囲の正常肝組織を圧排しながら急速に浸潤増殖する活性の高い腫瘍組織領域。

---

## 2. 原発巣によるエコー像の特徴

| 原発癌の種類 | 典型的な超音波像の特徴 |
| :--- | :--- |
| **大腸がん・胃がん** (大腸腺癌) | 著明な **Target sign (Bull's eye)**、内部石灰化を伴いやすい |
| **乳がん・平滑筋肉腫** | 内部の嚢胞状壊死 (Cystic necrosis) を伴いやすい |
| **腎がん・甲状腺がん** | 血管性に富み、全体が高エコー結節を呈しやすい |
| **小細胞肺がん・悪性リンパ腫** | 境界鮮明な著しい**低エコー結節**（嚢胞様低エコー） |
