# 転移性肝がん (Metastatic Liver Tumor) 超詳細診断プロトコル

> [!NOTE] 概要
> 転移性肝がんは全肝悪性腫瘍の中で頻度が極めて高く、大腸がん、胃がん、膵がん、乳がん、肺がんなど他臓器のがん細胞が血流（門脈または肝動脈）を介して肝実質に多発播種する病態です。超音波検査は多発結節の非侵襲的検出および原発巣の推定において決定的な役割を果たします。

---

## 1. 特徴的な超音波サインと病理組織学的解剖 (Acoustic Pathology)

```text
 ┌────────────────────────────────────────────────────────┐
 │ 1. Target Sign / Bull's Eye Sign (標的像・牛眼像)         │
 │ 2. 多発性結節 (Multiple Nodules): 両葉多発性           │
 │ 3. 集簇像・融合像 (Cluster Sign / Confluence Sign)       │
 │ 4. 肝外側縁の変形・凹み (Umbilication / Extrusion Sign)   │
 └────────────────────────────────────────────────────────┘
```

### Bull's Eye Sign / Target Sign の微細構造解剖
なぜ「中央が高エコーで、周縁が厚い低エコーリング」に見えるのか？

```text
       ┌────────────────────────┐
       │   [厚い周縁低エコー帯]   │ ← 急速に拡大・膨張発育する活性の高い癌浸潤帯
       │ ┌────────────────────┐ │   (腫瘍細胞の密度が極めて高く音響減衰が小さい)
       │ │   [中央高エコー部]   │ │ 
       │ │                    │ │ ← 腫瘍中央部の凝固壊死 (Coagulative Necrosis)、
       │ └────────────────────┘ │   出血、線維化、石灰化 (Rayleigh散乱)
       └────────────────────────┘
```

---

## 2. 原発巣（癌腫）による特徴的超音波所見の一覧

| 原発癌の種類 | 典型的な超音波像の特徴 | 組織学的背景 |
| :--- | :--- | :--- |
| **大腸がん・胃がん** (大腸腺癌) | 著明な **Target Sign / Bull's Eye Sign**、内部石灰化 (Hyperechoic Foci) | 腫瘍中央の粘液変性・石灰化・中央壊死 |
| **乳がん・平滑筋肉腫** | 内部の**嚢胞様低エコー壊死 (Cystic Necrosis)** | 虚血性壊死による液状化 |
| **腎細胞がん・甲状腺がん** | 境界鮮明な**高エコー結節 (Hyperechoic Mass)** | 多血性腫瘍 (Hypervascular tumor) |
| **小細胞肺がん・悪性リンパ腫** | 著明な**均一低エコー (Pseudo-cystic / Hypoechoic)** | 単一で高密度な小細胞増殖 |
| **膵管がん・胆管がん** | 境界不鮮明な不整型低エコー結節 | 線維性基質の強い硬がん |

---

## 3. Umbilication Sign (臍様陥凹像) と 肝輪郭の変形

- **Umbilication Sign**: 肝表面直下に存在する転移結節の中央部が壊死・線維性収縮を起こし、肝被膜が**内側に凹み（引き込まれ）をつくる**現象。
- **Extrusion Sign**: 逆に急速に発育する結節が肝被膜を**外側にドーム状に突き出させる**現象。

---

## 4. カラードプラ・造影超音波 (Sonazoid CEUS) 所見

- **カラードプラ**: 結節周縁に沿って走行する血管信号 (Peripheral Rim Vascularity) が特徴的。
- **ソナゾイド造影エコー (CEUS)**:
  - **血管相 (10～45秒)**: 結節周縁のリング状濃染 (Ring-like Enhancement)。
  - **Kupffer相 (10分後)**: 転移結節内にはKupffer細胞が皆無のため、すべての転移巣が**明瞭な黒い欠損像 (Defect Image)** として浮き彫りになる（微小転移の検出能が極めて高い）。
