# 急性・慢性膵炎 (Acute & Chronic Pancreatitis) 超詳細診断プロトコル

> [!NOTE] 概要
> 急性膵炎は自己消化による急性炎症・壊死を生じる重症疾患であり、慢性膵炎は可逆性のない線維化と外分泌・内分泌機能障害を進行させる疾患です。日本超音波医学会 (JSUM) 基準に基づく判定ポイントを解説します。

---

## 1. 急性膵炎 (Acute Pancreatitis) の超音波所見

```text
 ┌────────────────────────────────────────────────────────┐
 │ 1. 膵臓のびまん性/局所的腫大 (Diffuse/Focal Enlargement) │
 │ 2. 膵実質の低下 (Hypoechogenicity): 浮腫による全体的暗濁  │
 │ 3. 周囲脂肪組織の輝度上昇 (Peripancreatic Fat Stranding)│
 │ 4. 膵周囲・後腹膜液貯留 (Peripancreatic Fluid Collection) │
 └────────────────────────────────────────────────────────┘
```

### 1) 膵仮性嚢胞 (Pancreatic Pseudocyst)
- **発症期**: 急性膵炎発症後 4 週間以上経過して形成される被膜を有する液体貯留。
- **超音波像**: 境界鮮明な円形〜楕円形の**無エコー嚢胞像 (Anechoic Mass)**、後方エコー増強。内部に壊死デブリス（高エコー点状像）を伴うことがある。

---

## 2. 慢性膵炎 (Chronic Pancreatitis) の超音波所見

慢性膵炎では、不可逆的な組織破壊と線維化に伴う特徴的変化を認めます。

```text
 ┌────────────────────────────────────────────────────────┐
 │ 1. 膵石症・石灰化 (Pancreatic Stones / Calcification)   │
 │ 2. 主膵管の不規則拡張・数珠状変化 (Rosary MPD Extension) │
 │ 3. 膵実質の粗雑化・不均一化 (Coarse Echogenicity)        │
 │ 4. 膵臓の萎縮 (Atrophy) または変形                      │
 └────────────────────────────────────────────────────────┘
```

### 慢性膵炎の確診サイン
- **膵石 (Pancreatic Calculi)**: 膵実質内または主膵管内に認められる**強エコー結節 ＋ 明瞭な音響陰影 (Acoustic Shadow)**。
- **主膵管数珠状拡張**: 狭窄と拡張が交互に現れ、内腔が不規則に屈曲・拡張する像（主膵管径 > 3.0 mm）。
