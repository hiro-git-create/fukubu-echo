# 腹部超音波 標準計測手技マニュアル (Ultrasound Measurement Protocol)

> [!NOTE] 概要
> 超音波検査における正確な計測は、病態評価・経過観察・手術適応の判定において極めて重要です。本マニュアルでは、各臓器・血管・管腔構造の**具体的なキャリパー（カーソル）の置き方、断面の切り方、および測定誤差（偽性誤差）を防ぐテクニック**を解説します。

---

## 1. 血管系計測手技 (Vascular Measurement)

### 1) 腹部大動脈 (Abdominal Aorta: AAA) の計測

> [!IMPORTANT] 大動脈計測の絶対原則: Outer-to-Outer & 垂直計測
> 1. **Outer-to-Outer (外壁外縁から外壁外縁)**: 血管壁の外膜外縁から反対側の外膜外縁までを計測する（内腔のみの測定は壁内血栓を見落とし偽小化するため厳禁）。
> 2. **血管長軸に対して垂直**: 斜断（斜めにカット）すると内径が偽陽性に拡大（偽瘤化）するため、必ず血管走行に対して**直交（垂直）する短軸像**で最大径を計測する。

```text
 ┌────────────────────────────────────────────────────────┐
 │                      【大動脈短軸像】                   │
 │                                                        │
 │               + ─────── (外膜外縁) ─────── +           │
 │               │                            │           │
 │               │      ┌──────────────┐      │           │
 │  (壁内血栓)   │      │  (実効内腔)  │      │  (壁内血栓)│
 │  (Thrombus)   │      └──────────────┘      │ (Thrombus)│
 │               │                            │           │
 │               + ─────── (外膜外縁) ─────── +           │
 │                                                        │
 │   キャリパー設置: 外壁外縁(+) ─── 外壁外縁(+)         │
 └────────────────────────────────────────────────────────┘
```

#### 計測手順
- **手順 1**: 上腹部正中横断走査で腹腔動脈 (CA) 分岐部から両側腸骨動脈分岐部までスクリーニング走査。
- **手順 2**: 最も太い拡張部を同定し、プローブを微調整して血管中心軸と直交させる。
- **手順 3**: 短軸像において **最大前後径 (AP diameter)** および **最大横径 (Transverse diameter)** を **Outer-to-Outer** で計測。

---

### 2. 胆道系計測手技 (Biliary Measurement)

#### 1) 胆嚢壁厚 (Gallbladder Wall Thickness)
- **計測断面**: 胆嚢体部前壁（**肝臓と接している部位**）。
- **理由**: 腹壁側の前壁は消化管ガスや音響効果で偽性肥厚しやすいため、肝床に固定されている部位で測定する。
- **原則**: ビームと壁が垂直になる位置で、**第1層内縁から第3層外縁まで**を計測。正常 ≦ 3.0 mm。

#### 2) 総胆管内径 (Common Bile Duct Diameter)
- **計測断面**: 右肋間走査または右上腹部縦断像で、門脈幹の前頭側を走行する総胆管長軸像。
- **原則**: **Inner-to-Inner (内腔内縁から内腔内縁)** で最大径を計測。正常 ≦ 6.0 mm。

---

### 3. 膵臓・膵管計測手技 (Pancreas & MPD)

#### 1) 主膵管内径 (Main Pancreatic Duct)
- **計測断面**: 膵体部横断像（脾静脈の腹側）。
- **原則**: 高エコー壁の内側内腔（無エコー部）の前後径を **Inner-to-Inner** で計測。正常 ≦ 2.0 mm。

---

### 4. 腎臓計測手技 (Renal Measurement)

#### 1) 腎長径 (Kidney Length)
- **計測断面**: 腎長軸像（最長径が得られる傾きを探索）。
- **原則**: 上極外縁から下極外縁までの最長ライン（Pole-to-Pole）を計測。正常 9.0 ～ 11.5 cm。

#### 2) 腎実質厚 (Parenchymal Thickness)
- **原則**: 腎実質外縁から中心エコー複合体 (CEC) 外縁までの垂直距離を計測。正常 1.5 ～ 2.0 cm。
