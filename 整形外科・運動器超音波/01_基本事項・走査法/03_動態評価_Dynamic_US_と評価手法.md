# 動態評価 (Dynamic US) と評価手法

> [!NOTE] Dynamic USの利点
> 超音波検査最大の強みは、リアルタイムで患者に関節運動や筋肉収縮を行わせながら観察できる**動態評価（Dynamic Ultrasound）**です。MRIやCTの静止画では捉えられない機能的異常を診断します。

---

## 1. 動態評価の臨床的適応フロー

```mermaid
flowchart TD
    A["動態評価 (Dynamic US)"] --> B["引っかかり・Snapping"]
    A --> C["滑走性評価 (Fascial Gliding)"]

    B --> B1["肩峰下インピンジメント / ばね指 / 弾性股 / 尺骨神経脱臼"]
    C --> C1["術後瘢痕粘連 / 筋膜性腰痛 / 腱鞘炎"]
    D --> D1["膝MCL損傷 / 足関節ATFL損傷 / 肘MCL損傷"]
```
