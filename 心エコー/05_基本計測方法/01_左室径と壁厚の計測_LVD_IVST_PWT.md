# 左室径と壁厚の基本計測

左室の形態評価の基本となる、内径（LVD）と壁厚（IVST, PWT）の計測についての基準とピットフォールをまとめます。
計測値は、**左室肥大 (LVH)** の判定や収縮能 (Teichholz法) の算出に用いられます。

## 1. 観察・計測断面
- **推奨断面**: 傍胸骨左室長軸断面 (PLAX)
- **計測部位**: 僧帽弁尖の先端レベル（大動脈弁直下から心尖部方向へ少し下がった位置）で、左室長軸に対して**垂直**になるように計測する。
- **推奨モード**: 以前はMモードが主体であったが、現在は2D（Bモード）像上での直接計測が推奨されている（心室中隔が斜めにスライスされる過大評価を防ぐため）。

## 2. 計測タイミングと項目
### 拡張末期 (End-Diastole)
心電図の **Q波の開始点** または **左室径が最大となる時相**（僧帽弁閉鎖直後）。
- **IVSTd (心室中隔壁厚)**: 右室側の心内膜エコーから左室側の心内膜エコーまで。
- **LVDd (左室拡張末期径)**: 中隔の左室側心内膜から、後壁の心内膜まで。
- **PWTd (左室後壁厚)**: 後壁の心内膜から心外膜まで。（※腱索を後壁と誤認しないよう注意）

### 収縮末期 (End-Systole)
心電図の **T波の終末** または **左室径が最小となる時相**。
- **LVDs (左室収縮末期径)**: 最も左室内腔が狭くなった時点の内径。

## 3. 左室肥大 (LVH) の判定指標
計測値から **左室心筋重量 (LV Mass)** および **相対的壁厚 (RWT)** を算出し、左室形態を4つに分類します。

### 指標の算出
- **LV Mass Index (LVMI)** [g/m²] = LV Mass / 体表面積(BSA)
- **相対的壁厚 (RWT)** = (2 × PWTd) / LVDd

### 左室形態の4分類
| 分類 | LVMI (男 >115, 女 >95) | RWT (> 0.42) | 病態の例 |
| :--- | :--- | :--- | :--- |
| **正常 (Normal)** | 正常 (LVHなし) | ≤ 0.42 | 健常 |
| **求心性リモデリング (Concentric remodeling)**| 正常 (LVHなし) | **> 0.42** | 高血圧初期など |
| **求心性肥大 (Concentric hypertrophy)** | **増大 (LVHあり)** | **> 0.42** | 高血圧、AS、HCM |
| **遠心性肥大 (Eccentric hypertrophy)** | **増大 (LVHあり)** | ≤ 0.42 | AR、MR、DCMなど（容量負荷）|

## 4. ピットフォール
> [!WARNING]
> Mモード計測時の注意点
- プローブの角度が悪く、超音波ビームが左室長軸に対して斜めに入射している場合、Mモードで計測すると壁厚や内径が実態より大きく（過大評価）計測されてしまう。
- **対策**: 必ず2D像をよく観察し、心内膜が最もクリアに見え、かつ壁に対して垂直に計測できるライン（または2D上での直接計測）を採用する。
- 右室内に右室モデレーターバンドや腱索が張り出している場合、それを心室中隔の一部として含めて計測しないこと。
