# 肺動脈弁疾患 (Pulmonary Valve Disease: PR, PS)

## 1. 肺動脈弁閉鎖不全症 (Pulmonary Regurgitation: PR)

### 概要・病態
- 拡張期に肺動脈から右室へ血液が逆流する。
- 健常者でも微小なPR（生理的PR）を認めることが多い。
- **病態的PRの主要な原因**:
  - **二次性**: 肺高血圧症 (PAH) に伴う肺動脈弁輪の拡大が最も多い。
  - **一次性**: 先天性心疾患（ファロー四徴症の術後など）、感染性心内膜炎、カルチノイド。
- 右室への容量負荷をもたらし、進行すると右心不全に至る。

### Bモード・Mモード所見
- 肺動脈幹の拡大。
- 右室拡大（右室容量負荷所見）、心室中隔の奇異運動（Diastolic flattening）。

### ドプラ法による計測と重症度分類 (PR)
> [!IMPORTANT]
> 肺動脈弁の評価は傍胸骨大動脈弁レベル短軸断面が基本となるが、描出が難しい場合は右室流出路断面も活用する。

| 項目 | 軽症 (Mild) | 中等症 (Moderate) | 重症 (Severe) |
| :--- | :--- | :--- | :--- |
| **Jetの広がり** | 狭い、弁直下のみ | 中間 | **広い（RVOT全体）** |
| **Jetの長さ** | 短い | 中間 | **長い（三尖弁輪に達する）** |
| **CWドプラ波形の濃度** | 薄い | 中間 | **濃い（順行性血流と同等）** |
| **減衰の速さ (Deceleration)** | 緩やか | 中間 | **急激 (Steep deceleration)** |
| **Pressure half time: PHT** | 長い | - | **< 100 ms** (※重症では拡張早期に急速に圧格差が消失する) |
| **肺動脈末梢の血流** | 正常 | - | **拡張期の逆行性血流** |

*(※ ASE 2017 に準拠)*

## 2. 肺動脈弁狭窄症 (Pulmonary Stenosis: PS)

### 概要・病態
- 収縮期における右室から肺動脈への血流障害（右室圧負荷）。
- ほぼすべてが**先天性**（単独PS、ファロー四徴症など）であり、後天性は稀（カルチノイドなど）。
- 右室圧負荷により、右室肥大（RVH）を来す。

### 重症度分類 (PS)
ASEやACC/AHAのガイドラインにおける最大血流速度 (Vmax) と最大圧較差 (Peak PG) を基準とする。

| 項目 | 軽症 (Mild) | 中等症 (Moderate) | 重症 (Severe) |
| :--- | :--- | :--- | :--- |
| **最大血流速度 Vmax (m/s)** | < 3.0 | 3.0 - 4.0 | **> 4.0** |
| **最大圧較差 Peak PG (mmHg)** | < 36 | 36 - 64 | **> 64** |

*(※ エコーでのPeak PG = 4 × Vmax² で算出される。カテーテル検査のPeak-to-Peak圧較差とは異なる点に注意)*

### ピットフォール
- 肺動脈狭窄には、弁レベル（Valvular PS）以外に、**弁下狭窄**（右室流出路の肥大による漏斗部狭窄）や**弁上狭窄**（肺動脈主幹部・末梢の狭窄）が存在する。
- どこで血流速度が最大になっているか、カラードプラのモザイク（エイリアシング）の開始位置を正確に特定する必要がある。
