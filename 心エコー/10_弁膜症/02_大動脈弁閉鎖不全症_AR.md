# 大動脈弁閉鎖不全症 (Aortic Regurgitation: AR)

## 1. 概要・病態
- 拡張期に大動脈から左室へ血液が逆流する疾患。
- **病態**: 左室容量負荷 → 代償性の左室拡大（LVDd増大）、進行すると左室収縮能（EF）の低下を来す。
- **主要な原因**: 
  - 弁尖の異常（二尖弁、感染性心内膜炎、リウマチ性）
  - 大動脈基部の異常（大動脈拡張症、マルファン症候群、大動脈解離、大動脈炎症候群）

## 2. Bモード・Mモード所見
- **大動脈弁および大動脈基部**:
  - 弁尖の接合不良、肥厚、石灰化。
  - 大動脈基部（AoR）や上行大動脈の拡大の有無を必ず確認する。
- **左室所見**:
  - 左室拡大（LVDdの増大）。
  - Mモードで、逆流血流が僧帽弁前尖（AML）に当たることで生じる **Fluttering（細かな振動像）** が見られることがある。
  - 重症例では、左室拡張末期圧の急上昇により **僧帽弁の早期閉鎖 (Premature closure)** が生じることがある（急性ARなどで顕著）。

## 3. ドプラ法による計測と評価
> [!IMPORTANT]
> 複数の指標（カラードプラ、CWドプラ、PWドプラ）を組み合わせて総合的に重症度を判定する。

### 必須計測項目
1. **Vena contracta (VC) 幅 [mm]**: 傍胸骨左室長軸断面で、弁直下の逆流シグナルの最も狭い部分を計測。
2. **Jet幅 / LVOT幅比 [%]**: 同じく長軸断面で、左室流出路 (LVOT) の幅に対する逆流シグナル幅の割合。
3. **Pressure half time (PHT) [ms]**: 心尖部3腔・5腔断面で、CWドプラによる逆流波形の減衰時間を計測。
4. **下行大動脈の逆行性血流 (Holodiastolic flow reversal)**: 胸骨上窩アプローチでPWドプラを用い、拡張期全体にわたる逆行性血流があるか確認する。

### 定量評価 (PISA法による EROA, Regurgitant Volume)
- 心尖部からPISA半径 (r) を計測し、有効逆流弁口面積 (EROA) と逆流量 (Regurgitant Volume) を算出する。
- `EROA = (2πr² × Aliasing velocity) / Vmax`

## 4. 重症度分類 (ASE/JCS)
| 項目 | 軽症 (Mild) | 中等症 (Moderate) | 重症 (Severe) |
| :--- | :--- | :--- | :--- |
| **Vena contracta 幅 (mm)** | < 3 | 3 - 6 | **≥ 6** |
| **Jet幅 / LVOT幅 (%)** | < 25 | 25 - 64 | **≥ 65** |
| **Pressure half time: PHT (ms)**| > 500 | 200 - 500 | **< 200** |
| **逆流量 Regurgitant Volume (ml)**| < 30 | 30 - 59 | **≥ 60** |
| **有効逆流弁口面積 EROA (cm²)** | < 0.10 | 0.10 - 0.29 | **≥ 0.30** |
| **下行大動脈の血流** | 短い/拡張早期のみ | 中間 | **全拡張期 (Holodiastolic)** |

*(※重症度分類はJCS 2020/ASE 2017に準拠)*

## 5. ピットフォール・注意点
> [!WARNING]
> 急性ARと慢性ARの違いに注意！
- **急性AR**（感染性心内膜炎や大動脈解離による）の場合、左室はまだ拡大しておらず（LVDdは正常範囲）、急激な圧上昇によりPHTは著しく短縮（< 200ms）し、僧帽弁早期閉鎖を伴う。これは緊急手術の適応となるサインである。
- 二尖弁（BAV）に伴う偏心性の逆流ジェットの場合、Vena contracta幅は重症度を過小評価する可能性があるため、複数の指標での総合評価が必須である。
