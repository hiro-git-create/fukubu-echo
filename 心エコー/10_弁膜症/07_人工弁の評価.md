# 人工弁のエコー評価

人工弁には **機械弁 (Mechanical valve)** と **生体弁 (Bioprosthetic valve)**、およびカテーテル治療による **経カテーテル大動脈弁 (TAVI/TAVR)** がある。
全ての人工弁は自己弁に比べてやや狭小（生理的狭窄）であり、正常でも自己弁より高い血流速度を示す。

## 1. 評価の基本
- **人工弁の種類とサイズの把握**: 検査前に必ず、埋め込まれている人工弁の「種類（メーカー、モデル）」と「サイズ」を確認する。
- **Bモード/Mモードでの形態観察**:
  - 機械弁: 開閉運動（leaflet/diskの可動性）、弁周囲の異常エコー（血栓、疣贅、パンヌス）。
  - 生体弁: 弁尖の肥厚、石灰化、断裂の有無。
- **ドプラ法による血行動態評価**:
  - 最大血流速度 (Vmax)、平均圧較差 (mean PG)。
  - 有効弁口面積 (EOA) と Doppler Velocity Index (DVI)。
  - 逆流の有無と部位（弁内逆流か弁周囲逆流か）。

## 2. 大動脈弁位人工弁の正常値と異常基準
> [!IMPORTANT]
> 人工弁の機能不全を疑う最重要指標は、血流速度の「経時的悪化（ベースラインからの上昇）」である。

| 指標 | 正常 (Normal) | 異常疑い (Possible dysfunction) | 著明な異常 (Significant dysfunction) |
| :--- | :--- | :--- | :--- |
| **Vmax (m/s)** | < 3.0 | 3.0 - 4.0 | **> 4.0** |
| **mean PG (mmHg)** | < 20 | 20 - 35 | **> 35** |
| **DVI (LVOT VTI / AV VTI)** | ≥ 0.30 | 0.29 - 0.25 | **< 0.25** |
| **EOA (cm²)** | > 1.2 | 1.2 - 0.8 | **< 0.8** |
| **Acceleration Time (AT)**| < 80 ms | 80 - 100 ms | **> 100 ms** (※狭窄を示唆) |

## 3. 僧帽弁位人工弁の正常値と異常基準
| 指標 | 正常 (Normal) | 異常疑い (Possible dysfunction) | 著明な異常 (Significant dysfunction) |
| :--- | :--- | :--- | :--- |
| **Vmax (m/s)** | < 1.9 | 1.9 - 2.5 | **≥ 2.5** |
| **mean PG (mmHg)** | ≤ 5 | 6 - 9 | **≥ 10** |
| **DVI (LVOT VTI / MV VTI)** | < 2.2 | 2.2 - 2.5 | **≥ 2.5** |
| **EOA (cm²)** | ≥ 2.0 | 1.0 - 2.0 | **< 1.0** |
| **PHT (ms)** | < 130 | 130 - 200 | **> 200** |

## 4. 人工弁における特有の病態 (ピットフォール)
> [!WARNING]
> 機械弁は強い音響陰影（Acoustic shadowing）を引くため、カラードプラで弁後方の逆流や血栓を見逃しやすい。経食道心エコー（TEE）がしばしば必要となる。

1. **Patient-Prosthesis Mismatch (PPM)**:
   - 患者の体格に対して人工弁のサイズが相対的に小さすぎる状態。
   - 弁自体の開閉は正常だが、Vmax・PGが高く算出される。
   - 判定基準 (大動脈弁位): EOA index ≤ 0.85 cm²/m² (Moderate), **≤ 0.65 cm²/m² (Severe)**。
2. **弁周囲逆流 (Paravalvular Leak: PVL)**:
   - 弁輪と人工弁の縫合部（外側）から生じる異常な逆流。
   - 感染性心内膜炎（IE）による弁輪部膿瘍や縫合糸の破綻が原因となる。高度な場合は溶血性貧血や心不全を来す。
3. **弁内逆流**:
   - 生理的逆流: 機械弁の閉鎖時に見られるわずかな逆流（washing jet）。正常。
   - 病的逆流: 生体弁の劣化（断裂）や、機械弁のパンヌス・血栓による閉鎖不全。
4. **TAVI特有の所見**:
   - TAVI弁は弁尖内に留置されるため、自己弁の石灰化が残りやすく、ステントフレーム外側からの PVL が比較的多く見られる。
