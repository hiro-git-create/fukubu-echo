# 心エコー基準値参照＆学習用 Webアプリ (Echo Reference & Learning WebApp)

## 📌 プロジェクト概要と特徴
本プロジェクトは、心エコー（Echocardiography）の各種計測値に関する正常値（基準値）の閲覧・比較に加え、初学者向けの電子教科書やインタラクティブな計算電卓機能を備えたWebアプリケーションです。

### 主な特徴
- **電子教科書UI**: 心エコーの基本から応用までを学べる5つの章立て構成で、学習を段階的に進められるUIを提供します。
- **評価フローチャート機能**: 計測結果をもとに重症度などの診断評価を行うためのフローチャートを視覚的に表示します。
- **リアルタイム計算電卓**: 計測値を入力することで、BSAや連続の式など、臨床で必要な各種指標をリアルタイムに自動計算します。
- **学会別の基準値比較**: 日本超音波医学会 (JSUM)、日本循環器学会 (JCS)、米国超音波医学会 (ASE) など、異なるガイドラインに基づく基準値を簡単に比較・参照できます。
- **レスポンシブデザイン**: PC、タブレット、スマートフォンなど、多様なデバイスで快適に閲覧できるモダンなUIを採用しています。

## 🚀 クイックスタート（ローカル環境での実行）
開発環境やローカルPC上で動作確認を行うための手順です。
Node.jsがインストールされていることを前提とします。

1. **パッケージのインストール**
   ```bash
   npm install
   ```

2. **開発サーバーの起動**
   ```bash
   npm run dev
   ```
   コマンド実行後、ターミナルに表示されるローカルURL（例: `http://localhost:5173`）にブラウザでアクセスしてください。

## 🧮 サポートされている計算式（電卓機能）
インタラクティブな電卓機能では、以下の計算式をサポートしています。
- **BSA (体表面積)**: DuBois式等を用いた体表面積の計算
- **AVA 連続の式 (大動脈弁口面積)**: LVOT径、LVOT VTI、AV VTIを用いた弁口面積の算出
- **PISA法**: 僧帽弁逆流(MR)などの逆流量、有効逆流弁口面積(EROA)の計算
- **圧力較差**: ベルヌーイの簡易式 ($4v^2$) を用いた圧較差の計算
- その他、Teichholz法やSimpson法による左室容積・EF計算など

## 📦 ビルドとデプロイ手順（自宅サーバーへの設置）
本番環境（自宅サーバー等）へデプロイするための手順です。

1. **プロダクションビルドの作成**
   ```bash
   npm run build
   ```
   このコマンドを実行すると、プロジェクトルートに `dist` というディレクトリが生成されます。

2. **Webサーバーへの配置**
   生成された `dist` ディレクトリの中身を、自宅サーバーで稼働しているWebサーバー（Nginx, Apacheなど）のドキュメントルートに配置します。
   - Nginxの例: `/var/www/html/`
   - Apacheの例: `/var/www/html/` または `C:\xampp\htdocs\` (Windowsの場合)

## 🌐 ネットワーク・アクセス関連のアドバイス（自宅サーバー公開時）
自宅サーバーを外部ネットワークからアクセス可能にする場合、セキュリティに十分配慮する必要があります。現在は認証機能が未実装であるため、以下のいずれかの方法で安全な通信経路を確保することを強く推奨します。

### 1. セキュアなVPN・トンネリングツールの利用（推奨）
ルーターのポート開放（穴あけ）を行わず、安全に外部からアクセスする方法です。
- **Tailscale**: 非常に簡単に構築できるVPNです。自宅サーバーと閲覧用端末の両方にTailscaleをインストールすることで、安全なプライベートネットワーク経由でアクセスできます。
- **Cloudflare Tunnels**: Cloudflareを経由して自宅サーバーを公開する仕組みです。SSL化が容易で、Cloudflare Access機能と組み合わせることで強力なアクセス制御（メール認証など）を実装できます。

### 2. ポート開放を行う場合（非推奨・注意）
ルーターの設定でHTTP(80)やHTTPS(443)のポート開放を行う場合は、世界中からアクセス可能な状態になります。
**今後の課題と対策:**
本アプリ自体にはまだログイン等のセキュリティ認証機能が実装されていません。認証機能（アプリ側での実装、またはWebサーバー側でのBasic認証など）を「後で構築する」予定の場合は、それが完了するまでポート開放による公開は控え、まずは上記のVPNやトンネリングツールを用いたクローズドな環境で運用することをお勧めします。

## 📊 データ構造仕様と編集方法
アプリ内で使用されるデータ（基準値、電卓定義、フローチャート等）は、`public/data/echo_references.json` で一元管理されています。

### JSONスキーマの基本構造
JSONファイルは主に以下の配列で構成されています。

- `guidelines`: ガイドライン（学会等）の定義
- `metrics`: 各計測項目と基準値の定義
- `calculatorDef`: 電卓機能の入力項目と使用する計算式の定義
- `evaluationFlow`: 診断や評価を行うためのフローチャート定義

```json
{
  "guidelines": [ ... ],
  "metrics": [ ... ],
  "calculatorDef": [
    {
      "id": "ava_continuity",
      "name": "AVA 連続の式",
      "inputs": ["lvot_d", "lvot_vti", "av_vti"],
      "formulaId": "calculateAVA"
    }
  ],
  "evaluationFlow": [
    {
      "id": "as_severity",
      "name": "大動脈弁狭窄症(AS) 重症度評価",
      "nodes": [
        { "step": 1, "condition": "Vmax > 4.0", "result": "重症(Severe)" }
      ]
    }
  ]
}
```

### データの追加・修正手順
- **基準値の変更**: `metrics` 内の該当項目の数値を修正します。
- **新しい電卓の追加**: `calculatorDef` に新しいオブジェクトを追加し、入力項目（`inputs`）と紐づける計算関数のID（`formulaId`）を指定します。
- **フローチャートの変更**: `evaluationFlow` 内のノード条件や結果を修正します。

## 🛠 開発者向けガイド：新しい計算ツールの追加方法
独自の計算関数を追加し、電卓機能としてUIに表示させるための手順です。

1. **計算関数の実装**
   `src/utils/mathFormulas.js` を開き、エクスポートする関数を追加します。
   ```javascript
   // src/utils/mathFormulas.js の例
   export function calculateNewIndex(input1, input2) {
     return (input1 * input2) / 100;
   }
   ```

2. **JSONデータとのマッピング**
   UIコンポーネントが動的に関数を呼び出せるように、`public/data/echo_references.json` の `calculatorDef` に追加します。
   ```json
   {
     "id": "new_index_calc",
     "name": "新しい指標の計算",
     "inputs": ["input1", "input2"],
     "formulaId": "calculateNewIndex"
   }
   ```
   ※ `formulaId` には、`mathFormulas.js` でエクスポートした関数名と完全に一致する文字列を指定してください。フロントエンドのコード（電卓コンポーネント等）は、このIDを使って動的に計算を実行します。
