# 心臓の基本解剖とエコー断面 (Cardiac Anatomy & Echo Views)

心エコー図を正確に読影するためには、体腔内における心臓の立体的な位置関係と、エコーのビームがそれをどう切り取っているか（2D断面）をリンクさせる空間認識が必要です。

## 1. 体内での心臓の立体的な位置関係
心臓は胸腔内で「まっすぐ」立っているわけではなく、右側にねじれて倒れ込むように位置しています。

- **最も前（胸壁側）にある部屋**: **右室 (RV)**。エコーで体の表面（上側）に描出されやすい。
- **最も後ろ（背中側）にある部屋**: **左房 (LA)**。経食道エコー (TEE) では食道に最も近いため非常に綺麗に見える。
- **心尖部 (Apex)**: 左前下方（左側の第5肋間付近）を向いている。
- **大血管の位置関係**: 
  - 前から後ろに向かって、肺動脈 (PA) → 大動脈 (Ao) → 上大静脈 (SVC) の順に並ぶ。
  - 大動脈弁は心臓の中央（中心骨格）に位置し、他のすべての弁に囲まれている。

## 2. 3つの基本直交面 (Orthogonal Planes)
心エコーでは、心臓自身の長軸を基準とした「3つの直交する断面」で評価します。

1. **長軸断面 (Long-axis view)**:
   - 心臓を大動脈弁〜心尖部に向かって縦に真っ二つに切った断面。
   - 例: 傍胸骨左室長軸断面 (PLAX)、心尖部3腔断面 (AP3)。
2. **短軸断面 (Short-axis view)**:
   - 長軸に対して垂直に、心臓を輪切り (スライス) にした断面。
   - 例: 傍胸骨左室短軸断面 (PSAX)。大動脈弁レベル、僧帽弁レベル、乳頭筋レベル、心尖部レベルでスライスする。
3. **四腔断面 (Four-chamber view)**:
   - 長軸と短軸の両方に垂直に、心室と心房（4つの部屋）がすべて見えるように横に切った断面。
   - 例: 心尖部4腔断面 (AP4)。

## 3. エコー画像上の「向き」のルール
画像上の左右・上下が実際の解剖のどこに相当するかは、画面上の **マーカー（Index mark）** で決まります。

- **画面の上部 (Top)**: 常にプローブ（振動子）が当たっている皮膚表面側。
- **画面のマーカー側 (通常は右側)**: プローブのマークが向いている方向。
  - 心エコーの伝統的な表示法（循環器設定）では、**画像上の右側にマーカー** が置かれます。
  - 例：傍胸骨長軸断面では、マーカーは患者の右肩方向を向いているため、画面の右側が大動脈（右肩側）、左側が心尖部（左下腹部側）となります。
  - ※腹部エコーの設定（放射線科設定）ではマーカーが画面左側になるため注意が必要です。

## 4. 冠動脈との位置関係 (17セグメント)
心エコーの各断面は、特定の冠動脈支配領域を評価するために切り取られています。
- 前壁・前壁中隔・心尖部 ＝ **LAD (左前下行枝)**
- 側壁・後壁 ＝ **LCx (左回旋枝)**
- 下壁・下壁中隔・右室 ＝ **RCA (右冠動脈)**
