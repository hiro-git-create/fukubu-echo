# 収縮性心膜炎 (Constrictive Pericarditis: CP)

## 1. 概要・病態
心膜（壁側・臓側）が慢性的な炎症により線維化・石灰化して硬い「殻」のようになり、心臓の拡張が強く制限される疾患です。
原因：特発性、ウイルス性、結核性、心臓手術後、放射線治療後など。

両心室が硬い殻で囲まれているため、**高度の拡張障害（心不全）** と **静脈うっ滞** を来します。
臨床像や基本エコー所見が **拘束型心筋症 (RCM)** と極めて似ているため、両者の鑑別が最も重要になります（CPは手術で心膜を剥がせば治癒・改善する可能性があるため）。

## 2. Bモード・Mモード所見
- **心膜の肥厚と高輝度化 (石灰化)**: エコーだけでは分かりにくいことも多く、CT/MRIが有用。
- **両房の拡大**: 拡張障害により左房・右房が拡大する（ただしRCMよりは軽度なことが多い）。
- **心室の形態と機能**: 左室・右室の大きさは正常で、LVEFも保たれる。
- **下大静脈 (IVC) の拡張**: 著明な右心不全によりIVCが拡大し、呼吸性変動が消失する。
- **Septal bounce (中隔の異常運動)**:
  - 拡張早期に、心室中隔がプルッと振戦するような異常運動を示す。右室に急速に流れ込んだ血液が、硬い心膜に阻まれて中隔を左室側へ押し込むために生じる（CPに特徴的）。

## 3. 拘束型心筋症 (RCM) との鑑別 (ドプラ所見)
両者とも「拘束型パターン（E/A高値、DcT短縮）」を示しますが、CPは「心室筋自体は正常」、RCMは「心室筋自体が硬い」という決定的な違いがあります。

### 1) 組織ドプラ (e' 波) と Annulus reversus
- **RCM**: 心筋自体が硬いため、中隔 e' も側壁 e' も著明に低下する（< 5 cm/sなど）。
- **CP**: 心筋は正常であるため、e' は比較的保たれる。さらに、硬い心膜に癒着している側壁の動きが制限され、相対的に中隔の動きが代償的に大きくなる現象（**Annulus reversus: 中隔 e' > 側壁 e'** または中隔 e' ≥ 8 cm/s）が見られれば、CPを強く示唆する。

### 2) 呼吸性変動 (Ventricular interdependence)
- **CP**: 硬い殻（限られた空間）の中で両心室がスペースを奪い合う（心室間相互依存）ため、呼吸による血流変化が非常に大きい。
  - **吸気時**: 右室へ血液が多く入り、中隔が左室側に押されるため、**僧帽弁血流 (E波) は 25% 以上低下** する。
  - **呼気時**: 逆に左室へ血液が多く入るため、僧帽弁血流が増加する。
- **RCM**: このような顕著な呼吸性変動は見られない。

### 3) 肝静脈血流波形
- **CP**: 呼気時（右心への還流が減る時相）に、拡張期の逆行性血流（拡張期逆流波）が著明に増大する。

## 4. サマリー：CP vs RCM
| 指標 | 収縮性心膜炎 (CP) | 拘束型心筋症 (RCM) |
| :--- | :--- | :--- |
| **心室壁の肥厚** | なし | あり（アミロイドーシス等） |
| **Septal bounce** | **あり** | なし |
| **組織ドプラ (e')** | 保たれる (中隔e' > 側壁e') | 全体的に著明低下 (中隔e' < 側壁e') |
| **血流の呼吸性変動**| **著明 (> 25%)** | なし (< 15%) |
