# 心膜疾患と心臓腫瘍 サマリー一覧

心臓の周囲（心膜）の異常と、心腔内の異常構造物（腫瘍・血栓）のまとめです。

## 1. 心膜疾患のポイント
心膜（心外膜と壁側心膜）の間に液体が貯留する「心嚢液貯留」と、心膜が硬くなる「収縮性心膜炎」が代表的です。

| 疾患・状態 | 主なエコー所見と特徴 |
| :--- | :--- |
| **正常心嚢液** | 生理的に 10〜50 ml 存在。エコーでは左室後壁の背側に収縮期のみ 1-2 mm のecho-free spaceとして見える。 |
| **心嚢液貯留** | 全周性にecho-free spaceが広がる。<10mm(軽微), 10-20mm(中等度), >20mm(多量)。 |
| **心タンポナーデ** | 貯留液による心臓への圧迫。**右房虚脱 (収縮後期)・右室虚脱 (拡張早期)**、IVC拡張がみられる緊急病態。 |
| **収縮性心膜炎 (CP)** | 心膜の肥厚・石灰化。拘束型心筋症(RCM)と似た拡張障害を呈するが、**Septal bounce（中隔の異常運動）** や annulus reversus (中隔e' > 側壁e') が特徴。 |

## 2. 心腔内異常構造物 (Mass) の鑑別
心臓内に「何かがある（Mass）」を見つけた場合、それが【腫瘍】【血栓】【疣贅 (Vegetation)】【正常構造物（アーチファクト）】のいずれであるかを鑑別します。

### 代表的な腫瘍と血栓の好発部位
| 種類 | 最も多い部位 | エコーでの特徴 |
| :--- | :--- | :--- |
| **左房粘液腫 (Myxoma)** | 左房（心房中隔の卵円窩付近に茎を持つ） | 良性腫瘍の代表。ゼリー状で可動性が高く、拡張期に僧帽弁口へ落ち込みMS様症状を呈する。 |
| **左室心尖部血栓** | 左室心尖部 | 重症の心機能低下（広範前壁梗塞、DCM）に伴う血流うっ滞が原因。可動性があれば塞栓症リスク極大。 |
| **右房内血栓 (Thrombus-in-transit)** | 右房内（下大静脈から流入） | 深部静脈血栓 (DVT) が剥がれて肺へ飛んでいく途中の「ひも状（Snake-like）」の血栓。致命的な肺塞栓の直前状態。 |
| **疣贅 (Vegetation)** | 弁尖（特に閉鎖縁の血流の上流側） | 感染性心内膜炎 (IE)。弁の破壊（逆流）を伴い、ヒラヒラと激しく動く。 |
| **乳頭状弾性線維腫** | 大動脈弁や僧帽弁（血流の下流側） | 弁膜の良性腫瘍。イソギンチャクのようにモヤモヤした小さなmass。 |

### よく間違えられる正常構造物（ノーマルバリアント）
- **右房**: キアリ網 (Chiari network)、下大静脈弁 (Eustachian valve)、分界稜 (Crista terminalis)。
- **左心耳**: 櫛状筋 (Pectinate muscles) ※血栓と間違いやすい。
- **左室**: 偽腱索 (False tendon)。
