# ストレイン法 (GLS: Global Longitudinal Strain) の基礎と評価

心筋の「変形（ひずみ：Strain）」を計測することで、従来のLVEFでは捉えられない**微細な・早期の心筋障害**を検出する技術です。
主に 2D Speckle Tracking Echocardiography (STE) が用いられます。

## 1. GLS の概念
- **Strain (ひずみ)**: 心筋が収縮してどれだけ短縮・変形したかをパーセンテージ (%) で表したもの。
- 心室筋は主に長軸方向 (Longitudinal)、円周方向 (Circumferential)、径方向 (Radial) に収縮しますが、臨床で最も有用性が確立しているのが **長軸方向のストレイン (GLS)** です。
- 収縮時に心筋は短くなるため、正常な長軸ストレイン値は **マイナス (負の値)** となります。マイナスの絶対値が大きいほど、収縮能が良いことを示します。

## 2. 正常値と病的意義
### 正常値の目安
- ガイドライン上の正常値は **≤ -20%** （絶対値で 20% 以上）とされています。
- ※ただし、エコー装置のメーカー（GE, Philips, Canonなど）や解析ソフトウェアによって基準値が異なる（-18% 〜 -22%程度）ため、同一患者の経過観察は同一機種で行うことが推奨されます。

### LVEF と GLS の違い
- **LVEF**: 心腔の「容積の変化」を見る。心筋の一部が障害されても、他の部位が代償性に過収縮すればLVEFは正常に保たれる（HFpEFなど）。
- **GLS**: 心筋そのものの「動きの変形」を直接見る。局所の微小な障害を早期に検出できる。

## 3. 臨床的有用性 (GLSが活躍する疾患)
> [!IMPORTANT]
> 以下の疾患では、LVEFが正常でもGLSが早期から低下（絶対値が減少、例: -15%など）することが知られています。

1. **がん治療関連心機能障害 (CTRCD: Cancer Therapeutics-Related Cardiac Dysfunction)**:
   - アントラサイクリン系やトラスツズマブなどの抗がん剤による心筋毒性の早期発見（JASE『CTRCD心エコー図検査の手引 第3版』2026年2月改訂）。
   - LVEFが低下する前に、GLSがベースラインから **相対的に 15% 以上低下**（例: ベースライン -20% ➔ -17%未満へ悪化）した場合、**Subclinical CTRCD（早期心筋障害）** のサインとみなされ、循環器医へのコンサルトや心保護薬の開始が考慮されます。
2. **心アミロイドーシス (Cardiac Amyloidosis)**:
   - 特徴的なパターンとして、心室中隔や側壁の基部・中間部のストレインが著明に低下する一方、**心尖部のストレインが保たれる（Apical sparing pattern / "Cherry on top"）** ことが診断の強力な手掛かりとなります。
3. **肥大型心筋症 (HCM)**:
   - 肥厚した部位（例えば心室中隔基部）の局所ストレインが低下します。
4. **大動脈弁狭窄症 (AS)**:
   - 症状が出る前（無症候性重症AS）において、GLSの低下は心筋の線維化や予後不良のサインとして手術適応の参考にされます。

## 4. 解析・計測のピットフォール
> [!WARNING]
> Speckle Trackingは画質に大きく依存します。
- **フレームレートの最適化**: 40〜80 fps程度が推奨されます。低すぎるとスペックルを追跡できず、高すぎると解像度が低下します。
- **画像の欠損・Foreshortening**: 心尖部が真ん中に描出されていない、または側壁が見切れていると正確にトレースできません。
- **トレースの確認**: ソフトウェアが自動トレースを行いますが、必ず目視で心内膜境界が正しく追従しているか確認し、必要に応じて手動で修正します。
