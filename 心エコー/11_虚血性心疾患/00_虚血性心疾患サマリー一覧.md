# 虚血性心疾患 (IHD) サマリー一覧

心エコーにおける虚血性心疾患評価の基本である「冠動脈支配領域」と「壁運動評価」、および「致死的な合併症」のまとめです。

## 1. AHA 17セグメントモデルと冠動脈支配領域
左室を17の区域（セグメント）に分け、局所壁運動異常 (Regional Wall Motion Abnormality: RWMA) の部位から責任冠動脈を推定します。

| 冠動脈 | 主な支配領域 | 心エコーでの観察断面 (主な部位) |
| :--- | :--- | :--- |
| **LAD (左前下行枝)** | 前壁、前壁中隔、心尖部 | AP4 (中隔心尖側), AP2 (前壁全体), PLAX (前壁中隔) |
| **LCx (左回旋枝)** | 側壁、後壁 | AP4 (側壁), AP2 (下壁側壁側), PLAX (後壁の一部) |
| **RCA (右冠動脈)** | 下壁、下壁中隔、右室 | AP4 (下壁中隔基部), AP2 (下壁), RV-focused |

*(※心尖部 (Segment 17: Apical cap) は通常LADの支配領域となります)*

## 2. 局所壁運動のスコアリング (Wall Motion Score)
各セグメントの壁運動と壁厚の増加（収縮期の肥厚）を視覚的に評価し、スコア化します。

| スコア | 名称 | 状態 (壁の動き / 壁厚の増加) |
| :---: | :--- | :--- |
| **1** | **Normal (Normokinesis)** | 正常な内側への動き、正常な壁厚の増加（>30%） |
| **2** | **Hypokinesis (低下)** | 内側への動きが弱い、壁厚の増加が乏しい（<30%） |
| **3** | **Akinesis (無収縮)** | 内側への動きが全くない、壁厚の増加がない |
| **4** | **Dyskinesis (奇異性)** | 収縮期に外側へ膨隆する (心室瘤の形成など) |
| **5** | **Aneurysm (心室瘤)** | 拡張期も含め常に外側に瘤状に突出している |

- **Wall Motion Score Index (WMSI)** = (評価できた全セグメントのスコア合計) / (評価したセグメント数)
  - 正常は 1.0。数値が大きいほど広範囲の虚血/梗塞を示します。

## 3. 急性心筋梗塞 (AMI) の機械的合併症アラート
> [!CAUTION]
> 急性心筋梗塞の患者で、突然の血圧低下、ショック、新たな雑音が生じた場合は、以下の**機械的合併症（致死的）**を真っ先に疑い、迅速にエコーで除外・確認してください。

1. **心室中隔穿孔 (VSP: Ventricular Septal Perforation)**
   - 梗塞部位（特に前壁中隔や下壁中隔）の心室中隔に穴が開き、左右短絡（VSD様の血流）が生じる。
2. **乳頭筋断裂 / 機能不全による急性重症MR**
   - 特に下壁梗塞（RCA領域）に伴う**後内側乳頭筋**の断裂が多い（単一の血流支配であるため虚血に弱い）。Flail leafletを伴う。
3. **心室自由壁破裂 (Free Wall Rupture) / 心タンポナーデ**
   - 左室自由壁が破裂し、心嚢内へ急速に血液が貯留する。直ちに心嚢ドレナージと緊急手術が必要。
4. **仮性心室瘤 (Pseudoaneurysm)**
   - 自由壁が破裂したものの、心膜に覆われて血腫として局所にとどまっている状態。狭いネック（入口部）を持つのが特徴で、破裂リスクが極めて高い。
