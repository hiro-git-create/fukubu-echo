# 局所壁運動異常 (RWMA) と責任病変の同定

心エコー図検査における虚血性心疾患（狭心症、心筋梗塞）の診断の基本は、**「冠動脈の支配領域に一致した局所壁運動異常 (RWMA)」** を捉えることです。

## 1. 基本的な考え方
- 虚血に陥った心筋は、数秒以内に収縮が低下（Hypokinesis）または停止（Akinesis）します。
- 心筋全体がびまん性に動かない（DCMなど）のではなく、**「正常に動く部位」と「動かない部位」が混在していること** が虚血性心疾患の最大の特徴です。
- 異常部位がどの冠動脈の支配領域（LAD, LCx, RCA）に該当するかをマッピングします。

## 2. 断面別の冠動脈支配領域の評価

### 傍胸骨左室長軸断面 (PLAX)
- **前壁中隔 (Anteroseptal)**: **LAD** 領域。
- **後壁 (Inferolateral / Posterior)**: **LCx** または **RCA** 領域。
  - *(※ 正常では、収縮期に中隔と後壁が互いに近づき、均等に肥厚します。)*

### 傍胸骨左室短軸断面 (PSAX)
左室を輪切りにするため、全周のセグメントを評価するのに最も適しています。
- **前壁 (Anterior)・前壁中隔 (Anteroseptal)**: **LAD**
- **下壁中隔 (Inferoseptal)・下壁 (Inferior)**: **RCA**
- **後側壁 (Inferolateral)・前側壁 (Anterolateral)**: **LCx**
  - *(※ 乳頭筋レベルのPSA断面で、左室を時計の文字盤に見立てて評価します。)*

### 心尖部アプローチ
- **心尖部4腔断面 (AP4)**
  - 心室中隔（後部）: RCA (基部) / LAD (中間部〜心尖部)
  - 側壁: LCx (基部〜中間部) / LAD (心尖部)
  - 心尖部 (Apical cap): LAD
- **心尖部2腔断面 (AP2)**
  - 前壁: LAD
  - 下壁: RCA
- **心尖部3腔断面 (AP3)**
  - 前壁中隔: LAD
  - 後壁: LCx

## 3. ピットフォールと鑑別疾患
> [!WARNING]
> 壁運動異常 ＝ 虚血（冠動脈疾患）とは限らない！

壁運動異常を見た際は、冠動脈支配領域に「一致しているか」を確認し、以下の疾患を鑑別する必要があります。

1. **たこつぼ症候群 (Takotsubo Cardiomyopathy)**:
   - ストレスなどを契機に発症。心尖部を中心とした広範な無収縮 (Akinesis) と、心基部の過収縮 (Hyperkinesis) を呈し、「たこつぼ」のような形態になる。
   - 冠動脈支配領域（単一血管）に**一致しない**広範な異常が特徴。
2. **左脚ブロック (LBBB) / ペースメーカー留置後**:
   - 心室中隔の電気的な興奮が遅れるため、収縮早期に中隔が右室側へ奇異な動き（Septal flash / 奇異性運動）をする。これを虚血（中隔のRWMA）と誤認しないこと。
3. **心筋炎 (Myocarditis)**:
   - 炎症部位に応じた局所壁運動異常を呈することがあるが、冠動脈支配領域に合致しないことが多い。心膜液貯留を伴うことがある。
